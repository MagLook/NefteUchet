# Последние документы

Кнопка **«Последние документы»** в командной панели формы TL_Загрузка открывает стандартный список регистра сведений **TL_СоответствиеИсточников**.

Регистр хранит соответствие: внешний источник (UUID объекта в центральной базе или STS API) ↔ ссылка на созданный документ в БП ГИГ.

## Что показывает

| Колонка | Содержит |
|---|---|
| Тип | Тип объекта-источника (Поступление, ОтчётОРозничныхПродажах, ПКО, Перемещение, Списание и т.п.) |
| ИсточникUUID | UUID элемента в центральной базе |
| Ссылка | Ссылка на созданный документ или элемент справочника в БП ГИГ |
| ДатаПоследнейЗагрузки | Когда документ был создан или обновлён |
| ИдентификаторПоследнегоПакета | UUID пакета, в котором документ создавался |
| ХешПоследнегоПакета | Хеш содержимого пакета (используется для идемпотентности) |

## Как использовать

- Двойной клик по строке в колонке **Ссылка** — откроется стандартная форма соответствующего документа БП.
- Из формы документа клавиша **Дт/Кт** — покажет проводки, сформированные при проведении.
- Стандартные средства списка регистра позволяют фильтровать, сортировать, выгружать в Excel.

## Назначение регистра

Регистр обеспечивает **идемпотентность загрузки**: при повторной обработке того же пакета документы не создаются заново, обновляется только содержимое уже существующего документа (если изменилось). Контроль — по паре «ИсточникUUID + ХешПоследнегоПакета».

См. [faq_дубль_пакета](faq_дубль_пакета.md).
