# Неизвестный контрагент в пакете

В пакете указан контрагент с уникальным кодом, которого нет в карточках контрагентов БП ГИГ. Документ не создан, в подробном отчёте ошибок категория **НСИ_НеНайдена** с типом Контрагент.

## Три типичных сценария

### Сценарий 1. Контрагент уже есть в БП, но с другим кодом

Часто бывает: карточка контрагента в БП ГИГ заведена давно (вручную), а в центральной базе он же — с другим внутренним кодом.

**Что делать:**
1. В подробном отчёте посмотреть «Значение» — там обычно ИНН и название.
2. **Покупки → Контрагенты** → поиск по ИНН.
3. Если контрагент найден — открыть карточку.
4. Внести соответствие через регистр **TL_СоответствиеИсточников**:
   - **Все функции...** → Регистры сведений → TL_СоответствиеИсточников.
   - Кнопка «Создать».
   - Тип = «Контрагент».
   - ИсточникUUID = код из ошибки (длинная строка вида `7c3a9e85-...`).
   - Ссылка = найденный контрагент.
   - Записать.
5. В форме «Загрузка из STS» → **«Перезагрузить период»** → **«Да» (Дозагрузить)**.

### Сценарий 2. Новый контрагент — первый раз в нашей базе

Поставщик действительно новый — раньше с ним не работали.

**Что делать:**
1. **Покупки → Контрагенты → Создать**.
2. Заполнить: ИНН, наименование, юридический адрес, банковские реквизиты.
3. Открыть вкладку **Договоры**.
4. Создать договор «С поставщиком» с видом расчётов 60.01 / 60.02.
5. Сохранить контрагента.
6. В форме «Загрузка из STS» → **«Перезагрузить период»** → **«Да»** — автомаппинг по ИНН сработает.

### Сценарий 3. В пакете ошибка

Оператор центральной базы указал неверного контрагента (или удалил карточку, или опечатался в ИНН).

**Что делать:**
1. Согласовать с центральной базой — какой контрагент должен быть.
2. Оператор поправит в центральной базе.
3. Переформируется пакет.
4. После прихода нового файла — «Перезагрузить период» → «Да».

## Особый случай: ГАЗИНВЕСТГРУПП как контрагент

При передаче товара между организациями сети (День X — переход АЗС с Норд-Лайн на ГИГ) одна организация становится контрагентом другой.

В БП ГИГ нужно чтобы:
- ГАЗИНВЕСТГРУПП был в **Справочнике Организации** (как основная) **и** в **Справочнике Контрагенты** (с тем же ИНН).
- Норд-Лайн был в **Справочнике Контрагенты** (если приходят пакеты от него как от поставщика).

При первоначальной настройке (см. [первая_настройка](первая_настройка.md)) проверить наличие обеих карточек.

## Чтобы избежать ошибки в будущем

- При получении нового пакета по новому поставщику — сначала **создать карточку контрагента**, потом загружать пакет.
- Если контрагент впервые упомянут в центральной базе — попросить технолога/оператора передать ИНН и название заранее.
