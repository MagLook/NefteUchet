# Глоссарий: категории ошибок загрузки

Категории ошибок — перечисление **TL_КодОшибкиЗагрузки** в составе расширения. Каждая запись в регистре TL_ОшибкиЗагрузки относится к одной из 12 категорий ниже. В «Подробном отчёте ошибок» ошибки группируются по категориям с цветовой палитрой и блоком «Что делать».

## Серверные / сетевые ошибки STS

| Категория | Цвет | Описание |
|---|---|---|
| **STS_ОшибкаСервера** | ⚠ жёлтый | HTTP 500/502/503 от pos.autooplata.ru/tms. Серверная проблема STS, не настройка БП. Подождать 15-30 минут, повторить. |
| **STS_ОшибкаАвторизации** | 🔐 красный | HTTP 401/403. Проверить логин/пароль в «Настройки расширения → Подключение». Возможно истёк токен API. |
| **STS_ОшибкаСети** | 🌐 синий | Нет связи с сервером STS. Проверить интернет и VPN на сервере 1С. |

## Маппинг и сопоставление

| Категория | Цвет | Описание |
|---|---|---|
| **МаппингОплат_НеНайден** | 🔗 фиолетовый | В STS пришёл новый pay_type без записи в TL_МаппингОплат. Строки пропущены. Завести запись в «Маппинг видов оплат STS». |
| **ВидОперацииНеСопоставлен** | 📋 фиолетовый | Источник прислал вид операции, не покрытый связкой. Передать код разработчику. |

## Справочники и реквизиты

| Категория | Цвет | Описание |
|---|---|---|
| **НСИ_НеНайдена** | 📇 бирюзовый | Не найден элемент справочника (Контрагент / Номенклатура / Склад / Организация / Подразделение). Создать в БП ГИГ. |
| **СтавкаНДС_НеСопоставлена** | 💱 бирюзовый | Источник прислал неизвестную ставку НДС. Передать значение разработчику. |
| **СчётУчёта_НеОпределён** | 📊 бирюзовый | В карточке номенклатуры или учётной политике не задан счёт учёта. Заполнить «Счета учёта» в товаре. |
| **ОбязательноеПолеПусто** | 📝 бирюзовый | Источник не передал обязательное поле. Проверить пакет в центральной базе. |

## Бизнес-логика

| Категория | Цвет | Описание |
|---|---|---|
| **ОшибкаПроведения** | 🛑 красный | Документ создан, но не провёлся. Открыть документ, нажать «Провести», устранить причину (остатки, реквизиты). |
| **СуммаНеСходится** | 🧮 красный | Сумма в шапке документа не равна сумме строк. Проверить источник пакета. |

## Прочее

| Категория | Цвет | Описание |
|---|---|---|
| **Прочее** | ❓ серый | Категория-fallback для ошибок не покрытых остальными. Передать обслуживающей организации. |

## Как использовать категории

В «Подробном отчёте ошибок» (кнопка в форме «Загрузка из STS»):
- Ошибки сгруппированы по категориям.
- Цвет блока показывает класс (жёлтый = ждать, красный = действовать).
- Блок «Что делать» даёт пошаговую инструкцию.
- Ссылка «📖 Подробнее» открывает соответствующую статью из этой справки.
