# TradeLedger v6.0.0 — релиз для боевой БП ГИГ

**Дата:** 2026-05-12
**Файл:** `TradeLedger.cfe` (~144 КБ)
**База назначения:** БП ГИГ (192.168.40.31), Бухгалтерия предприятия 3.0, режим совместимости 8.3.24

---

## Что в релизе

### Главное исправление: разноска корпоративных продаж

В предыдущей версии **VIAcard и БАЛТОП ошибочно попадали в розничный отчёт** (видно на смене 3227 АЗС 210 от 29.04.2026 — ОРП ГИ0Г-000727 на 284 961,70 ₽ вместо корректных 87 656,67 ₽).

После накатки:

1. **Отчёт о розничных продажах** содержит **только розницу** (СберБанк-эквайринг + Наличные).
2. **VIAcard, БАЛТОП и прочие топливные карты** → Перемещение на склад «Карты», **без суммы** (расценка в конце месяца по договору с оператором).
3. **Яндекс / мобильные приложения** → Перемещение на склад «ЯНДЕКС».
4. **Ведомости** → Перемещение на склад «Ведомости».
5. **Талоны** → Перемещение на склад **«Талоны»** (новый виртуальный склад).

### Сменный отчёт в TradeLedger (HTML)

Для безналичных строк (VIAcard / БАЛТОП / ЯНДЕКС / Ведомости / Талоны) в денежных колонках стоит прочерк `—`. В шапке отчёта: «Учётная выручка смены: N ₽» (только розница) + «N литров безналично — к расценке в конце месяца».

### Новый регистр настроек: «Маппинг видов оплат STS на каналы и склады»

Открывается через меню **ElsyPlus Ledger** → «Маппинг видов оплат STS на каналы и склады».
При первой накатке заливается 15 правил по умолчанию (наличные, СберБанк, VIAcard, БАЛТОП, Яндекс, Ведомости, Талоны, корпоратив, топливн, агора, мобил, benzuber, купон, прокач).

Бухгалтер может править таблицу: добавлять новые операторы, менять привязку к каналу/складу, удалять ненужные.

### Защита от ошибок: блокер

Если в сменном отчёте от STS встретится **неизвестный вид оплаты** (например, новый оператор «GPN Карта»), документы по смене **не создаются**. Появится сообщение: «Не настроен маппинг для видов оплат: "GPN Карта". Откройте маппинг и укажите канал и склад». Лучше, чем тихо свалить в наличные как раньше.

## Подготовка перед накаткой (для бухгалтера ГИГ)

### Шаг 1. Завести в Catalog.Склады элемент «Талоны»

В справочнике **Склады**:
- Создать → Наименование: `Талоны`, Тип: Оптовый
- Можно поместить в ту же группу, где «Карты», «Ведомости», «ЯНДЕКС»

Без этого склада талоны не разнесутся.

### Шаг 2. Проверить актуальность привязки кодов АЗС к складам

В предыдущей конфигурации в настройках TradeLedger у станций стоят временные имена («АЗС №1»–«АЗС №6», «АЗС 5», и т.п.), хотя реальные склады переименованы в «АКЗС Витебский (5)», «АКЗС Колпино (6)» и т.д.

После накатки v6.0.0 откройте **Настройка расширения TradeLedger** → шаг «Станции АЗС → Склады 1С» и для каждой станции выберите правильный склад из справочника:

| Код | Должно быть |
|---|---|
| 1 | АКЗС Непокоренных (1) |
| 2 | АКЗС Выборг (2) |
| 3 | АКЗС Кудрово (3) |
| 4 | АКЗС Первомайское (4) |
| 5 | АКЗС Витебский (5) |
| 6 | АКЗС Колпино (6) |
| 8 | АЗС Светогорск (8) |
| 205 | АЗС Брусничное (205) |
| 207 | АЗС Выборг (207) |
| 208 | АЗС Выборг (208) |
| 209 | АЗС Светогорск (209) |

## Накатка расширения (для админа 1С)

### Шаг 1. Бэкап

В Конфигураторе 1С: **Администрирование → Выгрузить информационную базу** → сохранить `.dt`-файл. Желательно за пределами рабочего сервера.

### Шаг 2. Установка расширения

В Предприятии (или Конфигураторе):

1. Перейти в раздел **Администрирование → Печатные формы, отчёты и обработки → Расширения конфигурации**.
2. Если уже стоит предыдущая версия TradeLedger — нажать «Удалить» и подтвердить (данные регистров TL_Настройки и т.д. сохранятся).
3. Нажать **«Добавить из файла»** → указать `TradeLedger.cfe`.
4. После установки: **Главное меню → Все функции → Стандартные → Управление расширениями конфигурации** → перезапустить сеанс (или просто закрыть и открыть 1С).

При первом запуске после установки расширение само:
- Заполнит регистр настроек `TL_Настройки` дефолтными значениями (если пуст).
- Заполнит регистр `TL_МаппингОплат` 15 правилами по умолчанию.
- Подтянет склады «Карты», «ЯНДЕКС», «Ведомости», «Талоны» в маппинг (если они существуют в Catalog.Склады).

### Шаг 3. После накатки: чек-лист проверки

В порядке выполнения:

- [ ] Открыть **меню ElsyPlus Ledger** в боковом меню — должны быть пункты «Загрузка из TradeLedger», «Настройка расширения TradeLedger», «Маппинг видов оплат STS на каналы и склады».
- [ ] Открыть **Маппинг видов оплат** — должно быть 15 строк, у безналичных каналов колонка «Склад» заполнена.
- [ ] Открыть **Настройка расширения** → шаг «Станции АЗС → Склады 1С» → исправить привязки по таблице из «Шага 2 подготовки» (12 станций).
- [ ] Сохранить настройки.
- [ ] Загрузить тестовую смену, например свежую за сегодня → проверить:
  - Документ Отчёта о розничных продажах содержит только розничные литры (наличные + Сбербанк).
  - В вкладке «Безналичные оплаты» — сумма по эквайрингу Сбербанк.
  - Параллельно создан ПКО на наличные.
  - Если в смене были корпоративные карты — создано Перемещение на склад «Карты».
  - Если талоны — Перемещение на «Талоны».
- [ ] Открыть **HTML сменного отчёта** (детали смены) — у безналичных строк в денежных колонках прочерк, в шапке «Учётная выручка».

### Шаг 4. Битые документы прошлого

Документы Отчётов о розничных продажах, созданные старой версией с неправильной суммой (например ГИ0Г-000727 на 284 961,70 ₽), нужно либо:

- **Удалить** (пометить на удаление + перевыложить смену через **Загрузка из TradeLedger**); или
- **Поправить вручную** (убрать строки VIAcard/БАЛТОП из товарной части ОРП и завести Перемещения по литрам отдельно).

Рекомендация: первое — чище и быстрее. После накатки запустить **Загрузку → Все смены** за период с момента, когда стали попадать корпоративные карты в ОРП.

## Откат (если что)

В Конфигураторе **Расширения конфигурации** → выделить TradeLedger → «Удалить». Все справочники и регистры расширения исчезнут вместе с ним. Документы 1С (ОРП, ПКО, Перемещения) останутся.

Затем восстановить предыдущую версию `.cfe` из бэкапа.

## Вопросы и поддержка

- Если после накатки появилось сообщение «Не настроен маппинг для видов оплат: ...» — добавьте строку в Маппинг видов оплат с указанным именем, выберите канал и склад. Документы пересоздадутся при следующей загрузке смены.
- Если в Catalog.Склады нет нужного склада — заведите вручную перед добавлением в маппинг.
- Если что-то непонятно — пишите.
