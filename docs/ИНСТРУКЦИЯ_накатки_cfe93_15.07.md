# Накатка cfe93 — ТТН-агрегация + субконто топлива из карточки

Дата подготовки: 15.07.2026. Коммит: `5b696c7`. Накатывает МАГ вручную.

## Что входит (4 правки, 3 модуля)

| Модуль | Правка |
|---|---|
| `TL_ApiКлиент` | **Д1**: `ПолучитьПоступления` агрегирует танки одной ТТН по виду топлива (новые функции `АгрегироватьТанкиТТН`, `СложитьРазделТанка`, `ЧислоИзДанных`). Чинит потерю второго танка |
| `TL_МаппингЦБ` | **Д3**: `ОпределитьГруппуТопливаПоКарточке` (группа из карточки, fallback «Нефтепродукты (л)») вместо удалённой `ОпределитьНоменклатурнуюГруппуНефтепродукты`. **Д4**: `НайтиИлиСоздатьНоменклатурнуюГруппу` не плодит дубль при помеченной группе |
| `TL_СозданиеДокументов` | **Д3**: вызов новой функции в топливной строке ОРП. **Д6**: `ОбработатьСмену`/`ОбработатьТТН` — поиск живого документа по ключу в комментарии при пустом реестре (защита от дублей после «СбросРегистрации»), новая `НайтиДокументПоКлючуКомментария` |

⚠ В xml-v4 синхронизированы также `TL_Настройки` и `TL_СопуткаСервис` — там
теперь боевой код 10.07 (guard даты старта, фильтр станции в «Зачистить»),
который раньше был только в src. Накат из xml-v4 теперь безопасен.

## Порядок

1. Резерв: выгрузить текущее боевое расширение (Конфигуратор →
   Расширения → TradeLedger → Сохранить как .cfe).
2. Загрузить конфигурацию расширения из `xml-v4/` (или собрать
   `scripts/build.ps1` и подключить .cfe).
3. F7 не требуется (изменены только модули), но UpdateDBCfg не повредит.
4. **Обязательно: Проверка модулей (/CheckModules)** — модули компилируются лениво.

## Smoke после наката

1. Форма TL_Загрузка (режим Нефтепродукты) → период 10–11.07, станция 208 →
   список должен показать смены 7041/7042 и ТТН **11113 (ДТ, ~27 992 л = 2 танка)**,
   11108, 11161 — по одной строке на ТТН+топливо с СУММАРНОЙ массой.
2. НЕ грузить сразу всё: загрузить одну смену 7041 + её ТТН, проверить:
   - ОРП строки: субконто = «Нефтепродукты (л)» (карточки уже исправлены);
   - Комплектация 11113: масса = сумме двух танков, плотность ~826.9;
   - повторная загрузка той же смены → «уже загружен» (без дубля).
3. В ЖР не должно быть ошибок TL_МаппингЦБ/TL_СозданиеДокументов.
