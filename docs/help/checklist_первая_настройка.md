# Чек-лист: Первая настройка после установки расширения

Выполняется один раз после накатки расширения TradeLedger на боевую БП ГИГ.

## Предусловия

- Расширение TradeLedger накачено в БП ГИГ через интерактивный Конфигуратор.
- F7 выполнен, изменения приняты.
- В БП ГИГ заведена организация ГАЗИНВЕСТГРУПП с ИНН 7839440090.
- Согласован путь каталога OwnCloud с обслуживающей организацией.

## Чек-лист

### Шаг 1. Базовая инфраструктура
- [ ] В БП ГИГ существует организация ГАЗИНВЕСТГРУПП (Главное → Организации).
- [ ] У организации заполнены ИНН, КПП, юридический адрес, банковские реквизиты.
- [ ] В справочнике Подразделения организаций заведено подразделение для АЗС с «208» в наименовании.
- [ ] В справочнике Склады заведён склад с «208» в наименовании.
- [ ] В справочнике Контрагенты есть НОРД-ЛАЙН с ИНН 7804572748 (для приёма документов от прежней организации сети).
- [ ] В справочнике Статьи движения денежных средств есть «Розничная выручка».
- [ ] В справочнике Виды оплат организаций есть «Платежная карта».
- [ ] В справочнике Статьи затрат есть «Списание материалов».
- [ ] В справочнике Номенклатурные группы есть «Общепит» или «Производство» (любое из).

### Шаг 2. Настройка обмена Сопутки
- [ ] Открыть ElsyPlus Ledger → Сервис → TradeLedger — Настройка обмена: Сопутка.
- [ ] Нажать «Заполнить по умолчанию».
- [ ] Проверить подобранные значения (организация, контрагент, склад, подразделение, статья ДДС, вид оплаты).
- [ ] Заполнить «Каталог OwnCloud» — путь согласованный с обслуживающей организацией.
- [ ] Нажать «Проверить каталог» — должно сообщить количество tl_*.json (вначале обычно 0).
- [ ] Установить флаг «Проводить автоматически».
- [ ] Нажать «Сохранить настройки».

### Шаг 3. Настройка обмена Общепита
- [ ] Открыть ElsyPlus Ledger → Сервис → TradeLedger — Настройка обмена: Общепит.
- [ ] Нажать «Заполнить по умолчанию».
- [ ] Проверить значения: организация, подразделение, счета 44.01 / 41.02, статья затрат, номенклатурная группа.
- [ ] Если номенклатурная группа не подобралась — выбрать вручную.
- [ ] Установить флаг «Проводить автоматически».
- [ ] Нажать «Сохранить настройки».

### Шаг 4. Базовая проверка
- [ ] Открыть TL_Загрузка → переключить режим на «Сопутка» → дашборд показывает «Канал доступен».
- [ ] То же для режима «Общепит».
- [ ] Открыть TradeLedger — Просмотр сверки пакетов → пусто (за неимением пакетов) → форма открылась без ошибок.
- [ ] Открыть TradeLedger — Просмотр ошибок загрузки → пусто → форма открылась.

### Шаг 5. Smoke на тестовом пакете
- [ ] Получить от центральной базы тестовый пакет (1-2 строки).
- [ ] Положить файл tl_*.json в каталог.
- [ ] TL_Загрузка → «Опросить каталог» → должен показать 1 новый файл.
- [ ] «Обновить» → файл появляется во внешней таблице.
- [ ] Загрузить → проверить что документ создался.
- [ ] Открыть документ → проверить проводки (Дт/Кт).

### Шаг 6. Передача в работу
- [ ] Сообщить пользователю расширения что настройка завершена.
- [ ] Передать ссылку на справку (раздел ElsyPlus Ledger).
- [ ] Договориться о времени первой совместной загрузки реального пакета.
