# Чек-лист: Ежедневный приём пакетов

Выполняется один или несколько раз в день в зависимости от частоты поступления пакетов из центральной базы.

## Утренний приём (вчерашние смены)

### Шаг 1. Опрос каталога
- [ ] Открыть ElsyPlus Ledger → ElsyPlus Ledger — Загрузка документов.
- [ ] Кнопкой «Режим:» выбрать «Сопутка».
- [ ] Нажать «Опросить каталог» — журнал покажет сколько новых файлов и сколько уже загружено.
- [ ] Записать в свой журнал количество новых.

### Шаг 2. Загрузка пакетов сопутки
- [ ] Нажать «Обновить» — внешняя таблица заполнится.
- [ ] Отметить все строки (кнопка «Выбрать все»).
- [ ] «◀ Загрузить выбранные».
- [ ] Дождаться завершения, прочитать журнал.

### Шаг 3. Переключение на общепит
- [ ] Кнопкой «Режим:» выбрать «Общепит».
- [ ] Повторить шаги 1-2 для пакетов общепита.

### Шаг 4. Топливо (если приём через STS API)
- [ ] Кнопкой «Режим:» выбрать «Нефтепродукты».
- [ ] «Обновить» — данные подтянутся через STS API.
- [ ] Отметить и загрузить.

### Шаг 5. Контроль сверки
- [ ] Открыть TradeLedger — Просмотр сверки пакетов.
- [ ] Период по умолчанию — последние 7 дней. Можно сузить до вчера.
- [ ] Проверить статусы:
  - Зелёные — ничего не требуется.
  - Жёлтые — открыть «Показать ошибки пакета», см. [checklist_реакция_на_ошибку](checklist_реакция_на_ошибку.md).
  - Красные — то же, срочнее.
- [ ] Записать в журнал расхождения если они есть.

### Шаг 6. Подтверждение оператору
- [ ] Все пакеты обработаны — сообщить центральной базе (если требуется по регламенту).
- [ ] Записать в свой журнал: «Приём за дату N — N пакетов, M ошибок, расхождение X ₽».

## Дневной приём (текущие смены)

Аналогично утреннему, но обычно меньший объём. Период приёма зависит от регламента центральной базы (часто 12:00, 18:00, 24:00).

## Когда нужно подключить администратора расширения

- При появлении ошибок с кодом ОшибкаЗапроса.
- При расхождениях > 100 ₽ за один пакет.
- При систематических ошибках по одному поставщику.
- При недоступности каталога OwnCloud (журнал сообщает об ошибке проверки).
