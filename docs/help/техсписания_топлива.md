# Техсписания топлива (Прочие)

В сменном отчёте STS встречается тип оплаты **«Прочие»**. Это не продажа — это **технические операции** с топливом:

- Доливка топлива в мерник при поверке (метрологический контроль).
- Испарение в резервуарах (естественные потери при хранении).
- Технологический разлив при обслуживании ТРК (топливораздаточной колонки).
- Прокачка после ремонта оборудования.

Физически топливо ушло со склада АЗС, но за это никто не платил — нужно списать на расходы.

## Что делает расширение

Когда в сменном отчёте есть строки с pay_type=«Прочие», расширение автоматически создаёт **Документ.СписаниеТоваров** на склад АЗС:

| Реквизит | Значение |
|---|---|
| Вид операции | Списание со склада |
| Склад | АЗС где было списание |
| ТЧ Товары | Топливо (АИ-92 / АИ-95 / Дизельное топливо) в литрах |
| Комментарий | «Тех. списание топлива (Прочие) \| TL\|СМЕНА\|...\|СПИСАНИЕ» |

## Какие проводки

При проведении типовая БП формирует:

| Дт | Кт | Содержание |
|---|---|---|
| 91.02 (или счёт затрат из карточки) | 41.02 | Списание топлива на прочие расходы |

Конкретный счёт затрат зависит от настроек карточки номенклатуры топлива.

## Раньше как было

Раньше эти операции бухгалтер делал **вручную** — заводил Документ.СписаниеТоваров каждый раз когда видел в сменном отчёте строку «Прочие». Это занимало время и можно было забыть.

**Теперь автоматически** — расширение само создаёт документ при загрузке смены.

## Где посмотреть

1. **TradeLedger → Сверка пакетов с источником**.
2. Найти смену с pay_type=Прочие.
3. «Документы пакета» → найти «СписаниеТоваров».

Или через журнал:
1. **Склад → Списания товаров**.
2. Фильтр по дате — будут документы с префиксом «ГИОГ-» и комментарием «Тех. списание...».

## Если не работает

Если в смене были «Прочие», а документ списания не создался:

1. Открыть **TradeLedger → Маппинг видов оплат STS**.
2. Проверить что есть запись:
   - Образец имени: «прочи»
   - Канал: «writeoff_fuel»
   - Склад: пусто
3. Если записи нет — открыть **TradeLedger → Настройки расширения** → кнопка **«Заполнить настройки по умолчанию»**.
4. После добавления маппинга — «Перезагрузить период» → «Да» (Дозагрузить).

## Если смены без «Прочие»

Если в смене не было pay_type=«Прочие» — Списания не создаётся. Это норма — большинство смен идут без технических списаний.
