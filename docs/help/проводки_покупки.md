# Проводки покупки (поступление от поставщика)

kind пакета: **`purchase`**.

Создаётся документ **ПоступлениеТоваровУслугНаАЗК** (ПТУ).

## Проводки

Для табличной части «Товары» — на каждую позицию:

| Дебет | Кредит | Содержание |
|---|---|---|
| 41.02 | 60.01 | Оприходование товара (по закупочной цене без НДС) |
| 19.03 | 60.01 | НДС с поступления |

Если на счёт поставщика была предоплата, проводится автозачёт аванса:

| Дебет | Кредит | Содержание |
|---|---|---|
| 60.02 | 60.01 | Зачёт аванса (сумма не больше остатка по 60.02 для данного контрагента/договора) |

## Структура документа

- Шапка: дата, организация (ГИГ), контрагент-поставщик, договор, склад, валюта.
- Табличная часть «Товары»: номенклатура, количество, цена, ставка НДС, сумма НДС.
- Табличная часть «Услуги» (если есть) — аналогично, но без склада.

## Контроль

- Итоговая сумма ПТУ должна совпадать с суммой в первичных документах (УПД, накладная, счёт-фактура).
- НДС подставляется автоматически по ставке из карточки номенклатуры или из переданного значения.
- Если контрагент не найден в БП ГИГ — попадает в TL_ОшибкиЗагрузки с категорией НСИ_НеНайдена.

## Типовые проблемы

- **Контрагент не найден** — карточка контрагента в БП ГИГ отсутствует. Создать вручную через справочник Контрагенты или через автомаппинг по ИНН/UUID. См. [faq_неизвестный_контрагент](faq_неизвестный_контрагент.md).
- **Договор не определён** — у контрагента нет договора с нужным видом расчётов. Создать договор «С поставщиком» в БП ГИГ.
- **Счёт учёта пуст** — проверить регистр сведений «Счета учёта номенклатуры» для соответствующего склада.
- **Расхождение по НДС** — ставка НДС в карточке номенклатуры отличается от переданной в пакете. Согласовать с поставщиком.
