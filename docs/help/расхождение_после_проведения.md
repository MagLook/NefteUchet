# Статусы витрины, защита проведённых и знак ⚠

Слева в форме загрузки — список смен (витрина канала). Это «список дел»: по умолчанию
видны только смены, требующие вашего действия. Проведённые и не менявшиеся смены скрыты
(флажок «Показывать проведённые» включает показ всех).

## Статусы строк

- **«Загружен (не проведён)»** — расширение создало документы, они ждут вашей проверки и
  проведения.
- **«Проведён»** — вы уже провели, попало в бухучёт. В списке дел не показывается.
- **«⚠ Изменён в ЦБ после проведения»** — вы этот документ уже провели, а из центральной
  базы пришли **изменённые** данные по той же смене. Расширение **не стало молча
  переписывать** ваш проведённый документ (это защита проведённых, см. ниже), а пометило
  смену знаком ⚠.
- **«✖ Аннулирован (к удалению)»** — документ помечен на удаление: либо аннулирован в
  центральной базе (по смене пришла отмена), либо помечен вручную. Такие строки по
  умолчанию **скрыты** — как и проведённые. Чекбокс **«Показать аннулированные»** выводит
  их в витрину.

## Защита проведённых документов

Настройка `Защита_НеПерезаписыватьПроведённые` = 1 (включена по умолчанию).

Смысл: если документ смены **уже проведён** бухгалтером, повторная загрузка того же
пакета из ЦБ его **не перезаписывает** и не распроводит — бережёт вашу работу и ручные
правки. Если данные в ЦБ по такой смене изменились, расширение поднимает флаг, и смена
получает статус ⚠.

Отключать настройку (= 0) без необходимости не следует: тогда любая повторная загрузка
затрёт проведённые документы данными ЦБ.

## Где видно ⚠

- **Витрина (список смен)** — статус строки «⚠ Изменён в ЦБ после проведения».
- **Панель сопутки (дашборд)** — счётчик «⚠ На проверке» и красный баннер сверху:
  «N докум. изменены в ЦБ после проведения — требуют проверки».
- **Карточка смены** (двойной клик по строке) — бейдж «⚠ изменён в ЦБ после проведения»
  в шапке.

## Что делать при ⚠

1. Откройте смену → «Документы смены», сравните суммы/строки с новыми данными ЦБ.
2. **Если изменение существенное** — снимите проведение с документа и нажмите
   «Перезагрузить период» → «Да (Дозагрузить)»; расширение пересоздаст документ по
   актуальным данным ЦБ, затем проведите смену через витрину.
3. **Если изменение незначимо** или уже отражено вручную — оставьте как есть.

> Кнопка «Провести» в витрине **пропускает** ⚠-строки автоматически (не перепроводит их
> вслепую) — по ним нужно ваше решение.

Никогда не игнорируйте ⚠ при закрытии месяца: это метка расхождения ЦБ↔БП по конкретному
проведённому документу.

## Аннулированные документы (к удалению)

Аннулированные (помеченные на удаление) документы по умолчанию не видны в витрине — как и
проведённые. Чтобы разобрать их:

1. Включите чекбокс **«Показать аннулированные»** — строки появятся со статусом
   «✖ Аннулирован (к удалению)».
2. Кнопка **«Удалить выбранные»** снимает служебные ссылки расширения с выбранных
   документов и **каскадирует на парные Комплектации блюд** (чтобы не осталось «висящей»
   себестоимости).
3. Кнопка **«Зачистить аннулированные»** массово готовит к удалению все помеченные
   документы за период — удобно перед закрытием месяца.
4. Физически из базы документы убирает штатная операция 1С
   **«Администрирование → Удаление помеченных объектов»**.

Кнопка **«Провести»** в витрине аннулированные строки **пропускает** — проводить их не нужно.

## Не путать с «Расхожд. сумм ЦБ↔БП»

На панели сопутки в блоке «Сверка пакетов» есть показатель **«Расхожд. сумм ЦБ↔БП»** —
это суммовая сверка загрузки пакета (на сколько рублей сумма пакета ЦБ разошлась с суммой
созданных документов). Это **другое**, не связано со знаком ⚠ по проведённым документам.
Про суммовую сверку — [расхождение_в_сверке](расхождение_в_сверке.md).
