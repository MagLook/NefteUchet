# Загрузка пакета

Главная форма расширения — **TradeLedger → Загрузка из STS (топливо)**.

Через эту форму принимаются данные:
- Топливо — через STS API (онлайн, реальное время).
- Сопутка и общепит — пакеты JSON из каталога обмена с центральной базой ЭЛСИ.АЗК.

## Стандартный сценарий

1. Открыть форму **TradeLedger → Загрузка из STS (топливо)**.
2. Кнопкой **«Режим:»** в правом-верхнем меню «Ещё» выбрать контур: Нефтепродукты / Сопутка / Общепит. См. [переключение_режимов](переключение_режимов.md).
3. Для сопутки и общепита — сначала нажать **«Опросить каталог»** (в меню «Ещё»). Журнал покажет количество новых файлов и уже загруженных пакетов.
4. Указать период в полях **«Дата начала»** и **«Дата окончания»** (по умолчанию — текущий месяц).
5. По желанию — выбрать конкретную станцию в **«Код станции»** (0 = все).
6. Нажать **«Обновить»** — таблицы заполнятся данными.
7. В левой таблице — документы уже созданные в БП ГИГ. В правой — внешние данные из STS / центральной базы.
8. Отметить строки во внешней таблице → нажать **«◀ Загрузить выбранные»** — документы создадутся в БП.
9. При установленном флаге **«Проводить автоматически»** в настройках обмена — документы сразу проводятся. Иначе нажать **«Провести выбранные»** для отмеченных в левой таблице.

## Командная панель формы

| Кнопка | Действие |
|---|---|
| Обновить | Запросить свежие данные из источника |
| Перезагрузить период | Дозагрузить недостающее или перепровести существующие документы за период. См. [faq_перезагрузить_период](faq_перезагрузить_период.md) |
| Подробный отчёт ошибок | Открыть полноэкранный диагностический отчёт. См. [faq_подробный_отчёт_ошибок](faq_подробный_отчёт_ошибок.md) |
| Помощь | Открыть это содержание |
| Сбросить регистрацию | Удалить записи о загрузке за период (служебная операция) |

В меню «Ещё»: переключатель режима, унификация имён складов, опрос каталога, последние документы, экспорт дашборда.

## Контроль результата

После загрузки проверить:
- Дашборд KPI вверху — количество смен, ошибок, выручка.
- Журнал в верхнем правом блоке формы — текст результата по каждой строке.
- Раздел **TradeLedger → Сверка пакетов с источником** — итоги по пакету. См. [сверка_пакета](сверка_пакета.md).
- Раздел **TradeLedger → Журнал ошибок загрузки** — если есть записи, разобрать причины. См. [диагностика_ошибок](диагностика_ошибок.md).
- Кнопка **«Подробный отчёт ошибок»** — структурированный HTML-отчёт с категориями и рекомендациями.
