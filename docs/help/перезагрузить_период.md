# Кнопка «Перезагрузить период»

Универсальная кнопка-выручалочка. Делает три разных действия по выбору:
- **Дозагрузить** недостающие документы (безопасно).
- **Перепровести** существующие документы (обновляет проводки).
- (отдельная кнопка) **Сбросить регистрацию** (опасно).

## Когда нужна

### Сценарий 1 — добавили запись в маппинг оплат

В системе появился новый канал оплат (например, талоны), для него не было записи в маппинге. Несколько смен загрузились без перемещения на склад «Талоны». Запись в маппинг добавили — нужно дозагрузить недостающее за прошедшие дни.

### Сценарий 2 — изменили настройки учёта

Бухгалтер поменял счёт затрат в настройках обмена или счёт учёта в карточке номенклатуры. Старые документы стали с устаревшей логикой проводок — нужно перепровести.

### Сценарий 3 — реализован новый тип операции

Расширение получило обновление и теперь умеет автоматически списывать топливо для pay_type=«Прочие». Прошлые смены этого ещё не имеют — нужно дозагрузить.

### Сценарий 4 — синхронизировались рецепты блюд

В центральной базе технолог обновил ТТК. Старые ОРП за вчера были с одним рецептом, сегодня с другим. Если нужно перепровести вчерашние с новым — Перепровести.

## Как открывается

1. Заполнить **«Дата начала»** и **«Дата окончания»**.
2. По желанию — **«Код станции»** (0 = все станции).
3. Нажать **«Перезагрузить период»** в командной панели.
4. Появится диалог: «Найдено смен: N. Выберите действие».

## Что значит «Найдено смен»

Расширение посчитало все смены за период которые **уже загружались** ранее (есть запись в TL_СтатусыЗагрузки). Это и есть кандидаты для перезагрузки.

Если число = 0 — за этот период ничего ещё не загружали. Сначала используйте обычный сценарий загрузки через «Обновить» → «◀ Загрузить выбранные».

## Три действия в диалоге

### Кнопка «Да» — Дозагрузить недостающее

**Самый безопасный режим.** Для каждой смены:
- Если основной документ (ОРП) есть — не трогать.
- Если каких-то подключей не хватает (Перемещение на «Талоны», ПКО, Списание для «Прочие») — создать их.
- Если документ уже полный — пропустить.

**Дубли невозможны.** Можно нажимать без опасений.

### Кнопка «Нет» — Перепровести существующие документы

Для каждого документа из TL_СтатусыЗагрузки за период:
- Открыть документ.
- Записать с проведением.

Документы пересчитают проводки по текущей логике (учётной политике, настройкам). Новые документы не создаются.

Применяется если поменялись настройки учёта и нужно обновить проводки в старых документах.

### Кнопка «Отмена» — выход

Ничего не происходит.

## Кнопка «Сбросить регистрацию» — отдельно

В выпадающем меню **«Ещё»** (правый верхний угол формы) — пункт **«Сбросить регистрацию»**.

**Опасно. Двойное подтверждение.** Удаляет записи о загрузке из TL_СтатусыЗагрузки за период. Документы БП **не удаляются** — но связь между сменой STS и документом теряется.

Используется в редких случаях:
- Бухгалтер удалил документы вручную, но расширение про это «не знает» (по записям думает что смены загружены).
- Восстановление БД из бэкапа сбило синхронизацию.
- Нужна полная перезагрузка с пересозданием документов (сначала удалить документы → потом сброс → потом обычная загрузка).

Если не понимаете зачем — **не нажимайте**. Используйте «Перезагрузить период» → «Дозагрузить» в 95% случаев.

## Пример из жизни

**Ситуация:** за май было 358 смен, в маппинг 22.05 добавили канал voucher (талоны). 63 смены имели pay_type=«Талоны», но Перемещение на склад «Талоны» не создалось.

**Решение:**
1. Дата начала: 01.05.2026. Дата окончания: 22.05.2026. Код станции: 0.
2. «Перезагрузить период» → «Да» (Дозагрузить).
3. Диалог: «Найдено смен: 358. Выберите действие». Нажать «Да».
4. Лог: «Смена 208/2456: +1 док.», «Смена 209/3801: +1 док.», … 63 раза.
5. Итог: «Создано 63 документа на 4 661 040 ₽. Ошибок: 0».
6. Документы на склад «Талоны» появились.
