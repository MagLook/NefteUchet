# Какие документы создаёт расширение

Сводная таблица: какая операция на АЗС → какой документ в БП → какие проводки.

| Операция на АЗС | Документ в БП | Основные проводки |
|---|---|---|
| Поступление товара от поставщика | ПоступлениеТоваровУслуг (ПТУ) | Дт 41.02 / Кт 60.01 + Дт 19.03 / Кт 60.01 |
| Розничная продажа сопутки | ОтчётОРозничныхПродажах (ОРП) | Дт 90.02.1 / Кт 41.02 + Дт 62.Р / Кт 90.01.1 + НДС + оплата |
| Розничная продажа общепита | ОтчётОРозничныхПродажах (ОРП) — блюдо ОДНОЙ строкой как товар | Те же проводки, что у сопутки (блюдо = обычный товар) |
| Сборка блюда (себестоимость) | КомплектацияНоменклатуры (Комплектация) | Дт 41.02 (блюдо) / Кт 41.02 (ингредиенты) |
| Разбор блюда (возврат) | КомплектацияНоменклатуры (Разукомплектация) | Дт 41.02 (ингредиенты) / Кт 41.02 (блюдо) |
| Оприходование излишков (инвентаризация) | ОприходованиеТоваров | Дт 41.02 / Кт 91.01 (статья «Оприходование излишков») |
| Списание недостач (инвентаризация) | СписаниеТоваров | Дт 94 / Кт 41.02 |
| Возврат / корректировка поставщику | КорректировкаПоступления | Сторно проводок поступления (БУ+НУ) |
| Тех. списание топлива (Прочие) | СписаниеТоваров | Дт 91.02 (или счёт затрат) / Кт 41.02 |

## Подробнее по каждому документу

### Поступление товаров

См. [проводки_поступления](проводки_поступления.md).

Когда поставщик привозит партию чипсов или другого товара — оператор АЗС оформляет приёмку в центральной базе. Расширение создаёт в БП ГИГ ПТУ.

### Розничная продажа сопутки

См. [проводки_продажи_сопутки](проводки_продажи_сопутки.md).

Каждая смена ККМ за день формирует один ОРП. В нём — товары проданные за смену (чипсы, вода, сигареты) + расшифровка платежей (наличные/карты).

### Розничная продажа общепита (Вариант A)

См. [проводки_продажи_общепита](проводки_продажи_общепита.md) и [как_продаётся_блюдо](как_продаётся_блюдо.md).

Блюдо (Эспрессо, Капучино) продаётся в ОРП **одной строкой — как обычный товар** (с НДС 22%), так же как сопутка. Себестоимость блюда собирается **отдельным документом «Комплектация номенклатуры»**: ингредиенты (кофе, вода, стакан) списываются с 41.02 на собранное блюдо (Дт 41.02 блюдо ← Кт 41.02 ингредиенты). Возврат блюда отражается документом «Разукомплектация».

Отдельный документ ОПЗС (Отчёт производства за смену) **не создаётся**.

### Оприходование излишков / списание недостач

По результатам инвентаризации расширение создаёт **ОприходованиеТоваров** (излишки, Дт 41.02 / Кт 91.01, статья «Оприходование излишков») и **СписаниеТоваров** (недостачи, Дт 94 / Кт 41.02).

### Возврат / корректировка

См. [проводки_возврата](проводки_возврата.md).

Если после поступления выяснилось что часть товара бракованная или поставщик прислал меньше — оформляется через КорректировкаПоступления.

### Тех. списание топлива

См. [техсписания_топлива](техсписания_топлива.md).

Когда в сменном отчёте STS есть строки с pay_type=«Прочие» (доливка в мерник, испарение, тех. разлив) — расширение автоматически создаёт СписаниеТоваров.

## Где посмотреть конкретный документ

Способ 1 — через сверку:
1. **TradeLedger → Сверка пакетов с источником**.
2. Найти пакет за нужную дату.
3. Кнопка «Документы пакета» в командной панели.
4. Двойной клик на строке → откроется документ в БП.

Способ 2 — через журнал последних документов:
1. **TradeLedger → Загрузка из STS**.
2. В меню «Ещё» → «Последние документы».
3. Список всех созданных расширением документов с типом и пакетом.

Способ 3 — через стандартные журналы БП:
1. Покупки → Поступления (для ПТУ).
2. Продажи → Отчёты о розничных продажах (для ОРП).
3. Покупки → Корректировки поступлений (для возвратов).
4. Склад → Списания товаров (для тех. списаний).

## Как посмотреть проводки документа

1. Открыть документ.
2. На панели инструментов формы — клавиша **Дт/Кт** (или ПКМ → Показать проводки).
3. Откроется отчёт с группировкой по счетам.

## Откуда расширение берёт счета учёта

| Счёт | Источник |
|---|---|
| 41.02 | Карточка номенклатуры → Счета учёта |
| 19.03 | НДС — по виду номенклатуры |
| 60.01 / 60.02 | Договор с поставщиком → Виды расчётов |
| 90.01.1 / 90.02.1 / 90.03 | Стандартные для розницы |
| 62.Р | Стандартный для розницы |
| 50.01 / 57.03 | По виду оплаты — настраивается в **TradeLedger → Настройки обмена сопутки** |
| 44.01 | **В Варианте A не используется** — себестоимость блюд собирается Комплектацией на 41.02 |
| 91.01 | Оприходование излишков (статья «Оприходование излишков») |
| 94 | Списание недостач по инвентаризации |
| 68.02 | Стандартный для НДС |

## Если счёт подставился неправильно

- В карточке номенклатуры пусто → заполнить «Счета учёта».
- В настройках обмена неверный «Вид оплаты безнал» → поправить.
- Счёт 44.01 в Варианте A не используется (себестоимость блюд идёт через Комплектацию на 41.02) — заполнять не требуется.

Возможная категория ошибки в подробном отчёте: **СчётУчёта_НеОпределён**.
