# Документы и проводки по контурам

Сводная таблица: kind (тип пакета) → документ БП → проводки → раздел учёта.

| kind | Документ БП | Вид операции | Основные проводки | Раздел БП |
|---|---|---|---|---|
| `purchase` | ПоступлениеТоваровУслугНаАЗК (ПТУ) | Поступление | Дт 41.02 / Кт 60.01 — товар<br>Дт 19.03 / Кт 60.01 — НДС<br>Дт 60.02 / Кт 60.01 — автозачёт аванса (если был) | Покупки → Поступления |
| `retail_sale_sidegoods` | ОтчётОРозничныхПродажах (ОРП) | ОтчётККМОПродажах | Дт 90.02.1 / Кт 41.02 — себестоимость<br>Дт 62.Р / Кт 90.01.1 — выручка<br>Дт 57.03 / Кт 62.Р — эквайринг<br>Дт 50.01 / Кт 62.Р — наличные<br>Дт 90.03 / Кт 68.02 — НДС | Продажи → Отчёты о розничных продажах |
| `production_release` | ОтчётПроизводстваЗаСмену (ОПЗС) | ОтчётПроизводстваЗаСмену | Дт 41.02 / Кт 44.01 — выпуск (за каждое блюдо)<br>Дт 44.01 / Кт 41.02 — списание сырья (за каждый ингредиент) | Производство → Отчёты производства за смену |
| `return_purchase` | КорректировкаПоступления | СогласованноеИзменение | Обратные проводки оригинального поступления, формируются автоматически | Покупки → Корректировки поступления |
| `writeoff_fuel` | СписаниеТоваров | СписаниеСоСклада | Дт «счёт затрат из карточки» / Кт 41.02 — списание топлива (автоматически при проведении) | Склад → Списания товаров |

## Где посмотреть проводки конкретного документа

1. Открыть документ (через **TradeLedger → Сверка пакетов с источником** → «Документы пакета» или через стандартные журналы БП).
2. Нажать клавишу **Дт/Кт** на панели инструментов формы документа (или ПКМ → Показать проводки).
3. Откроется отчёт по проводкам с группировкой по счетам.

## Откуда берутся счета учёта

| Счёт | Источник |
|---|---|
| 41.02 | Карточка номенклатуры → Счета учёта |
| 19.03 | НДС поступления — определяется по виду номенклатуры |
| 60.01 / 60.02 | Договор с поставщиком → Виды расчётов |
| 90.01.1 / 90.02.1 / 90.03 | Стандартные для розничной торговли |
| 62.Р | Стандартный для розничного покупателя |
| 50.01 / 57.03 | По виду оплаты в РасшифровкеПлатежа ОРП — настраивается в **TradeLedger → Настройки обмена сопутки** |
| 44.01 | Из настроек обмена Общепита — поле «Счёт затрат» |
| 68.02 | Стандартный для НДС |

## Когда счета подставляются неправильно

- Карточка номенклатуры в БП ГИГ не заполнена счетами учёта — нужно либо заполнить, либо настроить через «Регистр сведений → Счета учёта номенклатуры». Категория ошибки: **СчётУчёта_НеОпределён**.
- В настройках обмена Сопутки указан неверный «Вид оплаты безнал» — поправить через **TradeLedger → Настройки обмена сопутки**.
- В настройках обмена Общепита счета 44.01 / 41.02 пустые или указаны другие — поправить через **TradeLedger → Настройки обмена общепита**.
