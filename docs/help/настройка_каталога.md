# Каталог обмена (OwnCloud)

Каталог — папка через которую центральная база ЭЛСИ.АЗК передаёт данные в БП ГИГ. Файлы пакетов формата **tl_*.json** записываются туда центральной базой, расширение их забирает.

Каталог общий для сопутки и общепита. Путь хранится в регистре сведений **TL_Настройки** под ключом **«КаталогOwnCloud_ЦБ»**.

## Два варианта транспорта

### Локальный каталог (для отладки)

Путь вида `D:\TL_BP_Export\`. Центральная база и БП ГИГ — на одной машине, обращаются к одной и той же папке.

Подходит только для тестирования. На боевой не используется.

### Синхронизированная папка OwnCloud (для боевой)

Один путь на сервере центральной базы, второй путь на сервере БП ГИГ. Между ними автоматическая синхронизация через rclone bisync с сервером OwnCloud.

Период синхронизации — 5 минут.

Это рабочий вариант когда центральная база и БП ГИГ на разных серверах.

## Где задаётся путь

В формах настройки обмена:
- **TradeLedger → Настройки обмена сопутки** — поле «Каталог OwnCloud».
- **TradeLedger → Настройки обмена общепита** — то же поле.

Достаточно ввести в одной из форм — общее значение сохранится для обеих.

## Проверка

В формах настройки кнопка **«Проверить каталог»** делает три проверки:
- Каталог существует.
- Каталог доступен на чтение.
- Сколько файлов с маской tl_*.json лежит сейчас.

Если каталог недоступен — журнал сообщит об ошибке.

## Кто настраивает путь на серверах

- **Локальный путь** — администратор расширения в БП ГИГ. Без обращения к обслуживающей организации.
- **Синхронизированная папка** — обслуживающая организация, через настройку rclone bisync. Запросить путь у них.

Бухгалтеру с серверами работать не нужно — только указать готовый путь в форме настроек.

## Что делать если каталог недоступен

1. Проверить интернет и VPN.
2. Проверить что сервер OwnCloud работает (страница входа открывается).
3. Если синхронизация настроена — связаться с обслуживающей организацией.
4. До восстановления — топливо через STS API работает независимо от каталога.
