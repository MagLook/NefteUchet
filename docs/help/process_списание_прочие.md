# Автосписание топлива (pay_type = «Прочие»)

В сменном отчёте STS встречается тип оплаты «Прочие» — он означает технические списания топлива (доливка в мерник при поверке, испарение, технологический разлив, обслуживание ТРК). Это не продажа — топливо физически уходит со склада АЗС без оплаты, должно быть списано на расходы.

## Как работает

Маппинг видов оплат настроен на канал **writeoff_fuel** для образца имени «прочи» (TL_МаппингОплат). При обработке сменного отчёта строки с pay_type=Прочие попадают в этот канал и группируются в один документ.

Для каждой смены, в которой есть такие строки, расширение создаёт один **Документ.СписаниеТоваров** с:
- ВидОперации = Списание со склада
- Склад = склад АЗС
- ТЧ Товары: топливо (АИ-92 / АИ-95 / Дизельное топливо) и количество в литрах
- Комментарий = «Тех. списание топлива (Прочие) | TL|СМЕНА|sysid|station|num|СПИСАНИЕ»

При проведении типовая БП 3.0 формирует проводки по карточке номенклатуры (обычно Дт 41.02 → Кт 41.02 по счёту учёта затрат или по счёту 91.02 «Прочие расходы»).

## Идемпотентность

Документ регистрируется в TL_СтатусыЗагрузки с ключом, отличным от основного ОРП. Повторная загрузка той же смены не плодит дубль СписаниеТоваров.

## Что увидит бухгалтер

После загрузки смены с такими строками:
- В журнале формы появится строка «Создано: 1 СписаниеТоваров (Прочие)».
- В БП появится документ с префиксом ГИОГ-NNN.
- В отчёте «Карточка счёта 41.02» виден расход топлива на эту АЗС с пометкой «Тех. списание».

## Как настроить если не работает

1. Открыть **TradeLedger → Маппинг видов оплат STS**.
2. Проверить запись «прочи» → канал «writeoff_fuel» → склад пуст.
3. Если записи нет — открыть **TradeLedger → Настройки расширения** → кнопка «Заполнить настройки по умолчанию».
4. Запустить «Перезагрузить период» → «Дозагрузить» — для уже загруженных смен догрузятся СписаниеТоваров.

## Когда списания нет

Если в смене не было pay_type=Прочие — СписаниеТоваров не создаётся. Это норма — большинство смен идут без технических списаний.

## История

Раньше эти строки требовали ручной обработки бухгалтером (ввод документа Списание со склада через интерфейс БП). После реализации канала writeoff_fuel — автоматизировано.
