# Диагностика ошибок загрузки

Два инструмента для разбора ошибок:

1. **Подробный отчёт ошибок** — кнопка в форме «Загрузка из STS» → открывается отдельное окно с группировкой по категориям и рекомендациями «что делать». См. [faq_подробный_отчёт_ошибок](faq_подробный_отчёт_ошибок.md).

2. **TradeLedger → Журнал ошибок загрузки** — табличный просмотр регистра TL_ОшибкиЗагрузки с фильтрами.

## Состав записи об ошибке

| Поле | Содержит |
|---|---|
| ВремяРегистрации | Дата и время момента ошибки |
| ИдентификаторПакета | UUID пакета (или КлючЗагрузки смены STS) |
| НомерЗаписи | Номер строки внутри пакета |
| ИсточникUUID | UUID объекта-источника |
| ТипОбъекта | Номенклатура / Контрагент / Поступление / Реализация и т.п. |
| Поле | Поле, на котором сработала ошибка |
| КодОшибки | Категория из перечисления TL_КодОшибкиЗагрузки. См. [gloss_коды_ошибок](gloss_коды_ошибок.md) |
| ЗначениеИсточника | Конкретное значение из пакета, вызвавшее ошибку |
| СообщениеОшибки | Текст ошибки в свободной форме |
| Документ | Ссылка на связанный документ, если есть |

## 12 категорий ошибок

| Категория | Что значит |
|---|---|
| STS_ОшибкаСервера | HTTP 5xx — серверная ошибка STS |
| STS_ОшибкаАвторизации | HTTP 401/403 — проверить логин/пароль |
| STS_ОшибкаСети | Нет связи с STS |
| МаппингОплат_НеНайден | Новый pay_type без записи в маппинге |
| ВидОперацииНеСопоставлен | Источник прислал неизвестный вид операции |
| НСИ_НеНайдена | Контрагент / Номенклатура / Склад / Организация / Подразделение |
| СтавкаНДС_НеСопоставлена | Неизвестная ставка НДС |
| СчётУчёта_НеОпределён | Не задан в карточке номенклатуры |
| ОбязательноеПолеПусто | Источник не передал обязательное значение |
| СуммаНеСходится | Сумма шапки ≠ сумма строк |
| ОшибкаПроведения | Документ создан, но не провёлся |
| Прочее | Категория-fallback |

Полное описание — [gloss_коды_ошибок](gloss_коды_ошибок.md).

## Фильтры в TL_ПросмотрОшибок

- **Дата начала / окончания** — период регистрации.
- **Фильтр тип объекта** — конкретный тип (например только ошибки по контрагентам).
- **Фильтр код ошибки** — конкретная категория.
- **Фильтр идентификатор пакета** — ошибки одного пакета.

После изменения фильтров — **«Обновить»**. Сброс — **«Сбросить фильтры»**.

## Типовой цикл разбора

1. В форме «Загрузка из STS» нажать **«Подробный отчёт ошибок»** — увидеть категории.
2. Для каждой категории прочитать «Что делать», при сложных случаях открыть «📖 Подробнее».
3. Устранить причину (создать справочник в БП, поправить пакет в центральной базе, добавить маппинг и т.п.).
4. После исправления — в форме «Загрузка из STS» нажать **«Перезагрузить период»** → **«Да» (Дозагрузить)**.
5. Снова открыть «Подробный отчёт ошибок» — категория должна исчезнуть.

История событий: записи в TL_ОшибкиЗагрузки не удаляются автоматически после исправления — остаются как журнал. При следующей загрузке появятся новые записи (без той же ошибки).
