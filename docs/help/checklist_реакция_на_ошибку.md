# Чек-лист: Реакция на ошибку загрузки

Выполняется при каждой записи в TL_ОшибкиЗагрузки с критичным кодом, а также при статусах пакета «ПринятоЧастично» или «Отклонено» в TL_СверкаПакета.

## Шаг 1. Идентификация

- [ ] Открыть TradeLedger — Просмотр ошибок загрузки.
- [ ] Сузить период до проблемного интервала.
- [ ] Для каждой красной строки записать:
  - ИдентификаторПакета
  - КодОшибки
  - Поле (на чём сработала)
  - ЗначениеИсточника

## Шаг 2. Классификация по коду ошибки

- [ ] Если **СправочникНеНайден**:
  - Контрагент → см. [faq_неизвестный_контрагент](faq_неизвестный_контрагент.md), создать карточку.
  - Номенклатура → создать карточку в БП ГИГ.
  - Склад / Подразделение / Организация → проверить и поправить настройки обмена.

- [ ] Если **ОтсутствуетОбязательноеПоле** или **НеверныйТипДанных**:
  - Согласовать с центральной базой — оператору переформировать документ.
  - После переформирования пакета — повторить «Перезагрузить пакет».

- [ ] Если **ОшибкаПроведения**:
  - Открыть документ через «Документы пакета».
  - Нажать «Провести» вручную, прочитать сообщение БП.
  - Устранить причину (счета учёта, остаток, политика).

- [ ] Если **ОшибкаЗапроса**:
  - Не пытаться разобрать самостоятельно.
  - Сделать скриншот формы с ошибкой.
  - Передать администратору расширения.

## Шаг 3. Применение исправления

- [ ] После правки в БП (создан контрагент, поправлена номенклатура):
  - В TradeLedger — Просмотр ошибок загрузки выделить строку → «Перезагрузить пакет».
  - Дождаться сообщения в окне.
  - Обновить форму, проверить что ошибка пропала.

- [ ] После правки в центральной базе:
  - Дождаться переформирования пакета (обычно несколько минут).
  - В TL_Загрузка «Опросить каталог» — увидеть обновлённый файл.
  - Загрузить пакет повторно через таблицу или «Перезагрузить пакет».

## Шаг 4. Контроль результата

- [ ] Открыть TradeLedger — Просмотр сверки пакетов.
- [ ] Найти пакет — Статус должен стать «ПринятоЦеликом».
- [ ] Колонка «Документов в БП» соответствует количеству строк документов.
- [ ] Расхождение нулевое или объяснимое (записать в комментарий).

## Шаг 5. Фиксация в журнале

- [ ] Записать в журнал: «Пакет UUID — ошибка код Х — устранено через Y — статус принято целиком».
- [ ] Если ошибка повторяющаяся — отметить для эскалации администратору.
