# Настройка обмена сопутки

Раздел: **TradeLedger → Настройки обмена сопутки (ЦБ → БП)**.

Форма задаёт параметры приёма пакетов сопутствующих товаров (чипсы, напитки, табак, журналы) из центральной базы ЭЛСИ.АЗК.

Обычно настраивается **один раз** при первой установке расширения. Бухгалтеру не нужно туда регулярно заходить.

## Первичная настройка

1. **TradeLedger → Настройки обмена сопутки (ЦБ → БП)**.
2. Кнопка **«Заполнить по умолчанию»** — расширение само подберёт:
   - Организация — ГАЗИНВЕСТГРУПП по ИНН 7839440090.
   - Контрагент-источник — НОРД-ЛАЙН по ИНН 7804572748.
   - Склад — первый склад с «208» в наименовании.
   - Подразделение — первое подразделение организации с «208».
   - Статья ДДС — «Розничная выручка».
   - Вид оплаты — «Платежная карта».
3. Проверить подобранные значения. При необходимости откорректировать.
4. Заполнить **«Каталог OwnCloud»** — путь к каталогу обмена.
5. Кнопка **«Проверить каталог»** — журнал сообщит количество файлов tl_*.json.
6. Установить флаг **«Проводить автоматически»** — да.
7. **«Сохранить настройки»** — в журнале появится подтверждение.

## Что хранится в настройках

Параметры лежат в регистре **TL_Настройки** под ключами с префиксом «Сопутка_». Менять напрямую не рекомендуется — только через эту форму.

## Когда повторно настраивать

- При смене каталога обмена с центральной базой.
- При смене основной организации в БП.
- При замене подразделения, склада, контрагента или статьи ДДС.
- При переходе следующей АЗС на ГАЗИНВЕСТГРУПП — после Дня X (поменять склад / подразделение если новые).
