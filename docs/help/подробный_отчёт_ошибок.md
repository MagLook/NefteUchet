# Кнопка «Подробный отчёт ошибок»

Главный инструмент диагностики. Открывает большое окно на весь экран с двумя частями:
1. **Сверху** — отчёт ошибок сгруппированный по категориям (или «✓ Ошибок нет» если их нет).
2. **Снизу** — журнал того что происходило в текущей сессии.

## Как открыть

В форме **TradeLedger → Загрузка из STS** в командной панели — кнопка **«Подробный отчёт ошибок»** (во второй строке).

Окно открывается **всегда**, даже если ошибок нет.

## Структура отчёта (если есть ошибки)

Ошибки за сегодня собираются в группы по категории. Каждая группа выглядит так:

```
⚠ Серверная ошибка STS (HTTP 5xx)              [ 2 ]
─────────────────────────────────────────────────────
Что делать: Это не настройка БП ГИГ. Подождите 15 минут
и повторите загрузку. Если ошибка повторится — обратитесь
в техподдержку pos.autooplata.ru с номером смены.
                                              📖 Подробнее

Время        | Пакет                  | Значение | Сообщение
─────────────┼────────────────────────┼──────────┼─────────────
22.05 09:15  | TL|СМЕНА|65|209|3866   |          | STS не вернул...
22.05 10:30  | TL|СМЕНА|65|209|3878   |          | STS не вернул...
```

Цветовая палитра — см. [категории_ошибок](категории_ошибок.md).

## Ссылка «📖 Подробнее»

Рядом с каждой категорией — ссылка **«📖 Подробнее»**. Клик открывает соответствующую статью из этой справки в отдельном окне.

Например:
- Для STS_ОшибкаСервера → откроется [реакция_на_ошибку](реакция_на_ошибку.md)
- Для МаппингОплат_НеНайден → [документ_не_создался](документ_не_создался.md)
- Для НСИ_НеНайдена → [неизвестный_контрагент](неизвестный_контрагент.md)

## Структура журнала (нижняя часть)

Светлый бежевый фон, чёрный моноширинный шрифт. Сюда попадают все сообщения формы за время текущего сеанса работы:

```
22.05 12:35  ✓ Подключение к STS API установлено
22.05 12:35  Обновление данных...
22.05 12:36  Внешних: 12, в 1С: 8
22.05 12:38  Загрузка 4 документов...
22.05 12:38  Загружено: 4 (документов в 1С: 12)
22.05 12:40  Открыт подробный отчёт ошибок
```

При закрытии формы 1С журнал очищается. При следующем открытии — пустой.

## Когда смотреть

### Каждое утро после загрузки

Нажать «Подробный отчёт ошибок» — если ✓ всё пройдено, можно работать дальше.

### Если что-то странное в работе

Например: загрузка завершилась, в журнале формы сообщение «Загружено: 5», но в БП появилось только 3 документа. Открыть отчёт — там увидите 2 ошибки которые не пустили оставшиеся документы.

### Перед закрытием месяца

Проверить что за месяц нет накопленных ошибок которые не отработали.

## Что НЕ показывается

- Ошибки старше сегодня — для них нужно открыть **TradeLedger → Журнал ошибок загрузки** (отдельное окно с фильтром по дате).
- Системные ошибки 1С (синтаксические, программные) — они идут в журнал регистрации 1С (Все функции → Стандартные → Журнал регистрации).

## Если ошибок нет — что показывает

В верхней части — зелёная плашка **«✓ Ошибок нет»**.

В нижней — журнал текущей сессии. Полезно увидеть что делалось.
