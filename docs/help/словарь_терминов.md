# Словарь терминов

Непонятные слова которые встречаются в расширении и в этой справке — простыми словами.

## Часто встречающиеся

**Расширение** — программа которая добавляется к 1С Бухгалтерии для дополнительной функциональности. TradeLedger — это и есть расширение. Можно представить как «надстройку» которая делает 1С умнее.

**Пакет** — файл с данными от центральной базы. Один пакет = один файл, содержит документы за одну смену одной АЗС или за период. Файлы лежат в специальной папке (см. [настройка_каталога](настройка_каталога.md)).

**Центральная база (ЦБ)** — это база ЭЛСИ.АЗК, где работают технологи и операторы АЗС. Из неё данные приходят в БП ГИГ через пакеты.

**Смена** — одна рабочая смена на АЗС. Обычно одна смена за сутки (или две если на АЗС круглосуточная работа). У каждой смены есть номер (например 3867) и дата.

**STS API** — способ получения данных о топливе с серверов pos.autooplata.ru. Расширение само подключается и забирает данные. Бухгалтер с STS напрямую не работает.

**АЗС** — автозаправочная станция. У каждой свой код (например 208 — это АЗС Выборг).

## Технические термины 1С

**Документ** — стандартная сущность 1С: Отчёт о розничных продажах, Поступление товаров, Списание товаров и т.д. Каждый документ имеет номер, дату и набор реквизитов.

**Проводка** — запись «Дебет / Кредит» в регистре бухгалтерии. Создаётся автоматически при проведении документа.

**Регистр сведений** — таблица служебных данных в 1С. Например в TL_СтатусыЗагрузки хранится список уже загруженных смен (чтобы не было дублей).

**Справочник** — список однотипных элементов: Контрагенты, Номенклатура, Склады. Хранится в БП и используется в документах.

**Спецификация номенклатуры (ТТК)** — рецепт блюда: что входит в Эспрессо, Капучино, Хот-дог. Хранится как элемент Справочника СпецификацииНоменклатуры с привязкой к блюду. См. [рецепты_блюд](рецепты_блюд.md).

**UUID** — уникальный код объекта в виде длинной строки (например `7c3a9e85-...`). Используется чтобы один и тот же контрагент или номенклатура в центральной базе и в БП ГИГ распознавались как одно и то же.

**Идемпотентность** — свойство «один и тот же пакет можно загружать сколько угодно раз — дубли не создаются». Обеспечивается через UUID-сопоставление.

**Пометка удаления** — стандартный способ удалить документ в 1С: сначала пометить на удаление, потом группой удалить через «Удалить помеченные». Прямого удаления нет.

**Проведён / Не проведён** — статус документа. Проведённый формирует проводки, не проведённый просто хранится в журнале без эффекта.

## Бухгалтерские счета (что значат)

**41.02** — «Товары в розничной торговле». На нём учитываются товары и ингредиенты блюд по продажной стоимости.

**44.01** — «Издержки обращения». Был основным счётом общепита в старой модели A (через выпуск). В новой модели B общепит на него не попадает.

**60.01 / 60.02** — Расчёты с поставщиками. 60.01 — задолженность поставщику. 60.02 — авансы поставщику.

**62.Р** — Расчёты с розничными покупателями (промежуточный счёт для розницы).

**90.01.1** — Выручка от продаж.

**90.02.1** — Себестоимость продаж.

**90.03** — НДС с продаж.

**50.01** — Касса в рублях (для наличных).

**57.03** — Денежные средства в пути (для эквайринга — переводы по картам).

**68.02** — НДС к уплате в бюджет.

**19.03** — НДС по приобретённым материально-производственным запасам.

## Категории ошибок

См. [категории_ошибок](категории_ошибок.md) — полный список с описанием.

Самые частые:

- **STS_ОшибкаСервера** — серверу плохо. Не ваша вина, подождать.
- **МаппингОплат_НеНайден** — новый вид оплаты, нужно завести запись в маппинге.
- **НСИ_НеНайдена** — не найден контрагент / товар / склад. Создать в БП ГИГ.
- **ОшибкаПроведения** — документ создан но не провёлся. Открыть, попробовать вручную.

## Кнопки расширения

**Обновить** — запросить свежие данные из источника (STS или каталог).

**Перезагрузить период** — дозагрузить недостающее или перепровести существующее за период. Кнопка-палочка-выручалочка. См. [перезагрузить_период](перезагрузить_период.md).

**Подробный отчёт ошибок** — открывает большое окно с диагностикой. См. [подробный_отчёт_ошибок](подробный_отчёт_ошибок.md).

**Помощь** — открывает это содержание.

**Сбросить регистрацию** — в выпадающем меню «Ещё». Удаляет служебные пометки расширения для периода. Опасная операция, использовать редко.

**Опросить каталог** — в меню «Ещё». Для сопутки и общепита — просмотр папки на наличие новых файлов.
