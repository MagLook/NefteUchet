# Сверка пакета

Раздел: **TradeLedger → Сверка пакетов с источником**.

Форма показывает записи регистра сведений **TL_СверкаПакета** — итоги по каждому принятому пакету.

## Состав строки

| Поле | Содержит |
|---|---|
| ИдентификаторПакета | UUID пакета |
| ВремяЗагрузки | Когда пакет принят |
| Источник | Откуда пакет (ЦБ.Сопутка, ЦБ.Общепит, STS.Топливо) |
| ПериодС / ПериодПо | Период, который покрывает пакет |
| СтрокНСИ | Количество строк нормативно-справочной информации в пакете |
| СтрокДокументов | Количество строк документов |
| СуммаЦБ | Сумма по данным центральной базы |
| СуммаБП | Сумма по созданным документам |
| Расхождение | СуммаБП − СуммаЦБ |
| Статус | ПринятоЦеликом / ПринятоЧастично / Отклонено |
| Комментарий | Свободный текст |
| **Ошибок** | Количество записей в TL_ОшибкиЗагрузки по этому пакету |
| **ДоктовБП** | Количество документов, созданных в БП по этому пакету |

## Цветовая подсветка

- **Светло-зелёный фон строки** — Статус «Принято целиком»
- **Светло-жёлтый** — «Принято частично»
- **Светло-красный** — «Отклонено»
- **Жирный красный** в колонке Расхождение — расхождение больше 0.01 ₽

## Итоги

В заголовке формы отображается:
- Найдено пакетов с разбивкой по статусам (Целиком / Частично / Отклонено)
- Итого сумма ЦБ, сумма БП, расхождение

Эти данные удобно копировать в отчёт за день / месяц.

## Действия по строке

- **«Показать ошибки пакета»** — открывает форму **TradeLedger → Журнал ошибок загрузки** с фильтром по выделенному пакету.
- **«Документы пакета»** — открывает стандартный список регистра TL_СоответствиеИсточников с фильтром по пакету. Из списка двойной клик по ссылке — откроется документ.

## Типовой цикл

1. Утром — открыть форму, фильтр за вчерашний день.
2. Все строки зелёные — приём прошёл штатно, можно перейти к проверке проводок.
3. Жёлтые — пакет частично принят: открыть «Ошибки пакета», разобрать причины недостающих строк, при необходимости — в форме «Загрузка из STS» нажать «Перезагрузить период» → «Да» (Дозагрузить).
4. Красные — пакет отклонён: открыть «Ошибки пакета», устранить корневую причину в центральной базе, перезагрузить.
5. Если есть расхождение в «Принято целиком» (например, копейки округления при пересчёте суммы) — записать в комментарий причину, чтобы при следующей сверке не пересматривать.
