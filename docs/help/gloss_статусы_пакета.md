# Глоссарий: статусы пакета

Поле **Статус** в регистре TL_СверкаПакета показывает результат обработки пакета.

## Возможные значения

### ПринятоЦеликом
- Все строки пакета успешно обработаны.
- Все документы созданы и проведены (или подготовлены, если автопроведение выключено).
- TL_ОшибкиЗагрузки по этому пакету пуст (или содержит только предупреждения).
- В сверке строка подсвечена **светло-зелёным**.
- Действие: ничего не требуется. При необходимости — проверка проводок через «Документы пакета».

### ПринятоЧастично
- Часть строк обработана успешно, часть — с ошибками.
- Количество созданных документов меньше количества строк документов в пакете.
- В TL_ОшибкиЗагрузки есть критичные записи.
- В сверке строка подсвечена **светло-жёлтым**.
- Действие: нажать «Показать ошибки пакета», устранить причины, в форме «Загрузка из STS» нажать **«Перезагрузить период»** → **«Да» (Дозагрузить)**.

### Отклонено
- Пакет не обработан вообще или обработано меньше половины строк.
- Возможные причины: неверный формат файла, отсутствие настроек обмена, недоступность каталога.
- В сверке строка подсвечена **светло-красным**.
- Действие: разобраться с причиной (открыть «Показать ошибки пакета»), исправить, перезагрузить.

## Особый случай

### Пакет в сверке отсутствует
- Если файл tl_*.json лежит в каталоге, но в TL_СверкаПакета записи нет — значит обработка ещё не запускалась.
- Действие: открыть форму «Загрузка из STS» → в меню «Ещё» нажать «Опросить каталог» → загрузить вручную через таблицу.
