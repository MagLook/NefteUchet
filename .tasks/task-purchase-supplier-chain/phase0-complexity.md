# Оценка сложности

Уровень: критическая.

Причины:

- сквозное изменение Edge → центральный Ledger → ЦБ → БП ГИГ;
- мастер-данные поставщиков и договоров влияют на юридически значимые документы;
- складские движения, НДС и повторная доставка требуют строгой идемпотентности;
- часть бухгалтерских правил по услугам, УПД и обратной таре ещё не определена;
- миграция затрагивает грязные и неполные данные действующей ЦБ.

BSL нельзя изменять до согласования архитектуры и правил учёта.
