# Чек-лист: Закрытие месяца

Выполняется в первой декаде следующего месяца после окончания приёма пакетов за отчётный месяц.

## Шаг 1. Проверка полноты приёма

- [ ] Открыть **TradeLedger → Сверка пакетов с источником**.
- [ ] Указать период — весь отчётный месяц.
- [ ] Проверить количество пакетов:
  - Сравнить с журналом ежедневного приёма — все ли смены центральной базы пришли.
  - Сравнить с центральной базой — все ли смены выгружены.
- [ ] Если есть недостающие пакеты — запросить переформирование в центральной базе.

## Шаг 2. Сверка по статусам

- [ ] Все пакеты должны быть «ПринятоЦеликом» или «ПринятоЧастично» с понятным комментарием.
- [ ] «Отклонено» — недопустимо для закрытого месяца, разобрать и принять.

## Шаг 3. Сверка сумм

- [ ] Итого сумма ЦБ vs Итого сумма БП — расхождение по модулю не должно превышать допустимое значение (обычно <0.5% от оборота).
- [ ] Если расхождение больше — разобрать каждый пакет с расхождением, см. [faq_расхождение_в_сверке](faq_расхождение_в_сверке.md).

## Шаг 4. Сверка по контрагентам (поставщикам)

- [ ] В стандартном отчёте БП «Расчёты с поставщиками» (по сч. 60.01 / 60.02) — проверить остатки.
- [ ] Сверить с актами сверки поставщиков (за месяц или за квартал).
- [ ] При расхождениях — найти оригинальные ПТУ через **TradeLedger → Сверка пакетов с источником** → «Документы пакета».

## Шаг 5. Сверка по 41-м счетам (товары)

- [ ] Отчёт «Оборотно-сальдовая ведомость» по счёту 41.02 за месяц.
- [ ] Сверить с центральной базой — отчёт об остатках товара на конец периода.
- [ ] Допустимое расхождение в количественном выражении — нулевое (если расхождение есть — разбирать каждую SKU отдельно).

## Шаг 6. Розничная выручка

- [ ] Отчёт «Карточка счёта 90.01.1» за месяц.
- [ ] Сверить с фискальными отчётами ККМ за месяц.
- [ ] При расхождениях — проверить полноту приёма ОРП и каналов оплат.

## Шаг 7. Финальная проверка ошибок

- [ ] В форме «Загрузка из STS» нажать **«Подробный отчёт ошибок»**.
- [ ] За месяц не должно быть ошибок категорий: НСИ_НеНайдена, СтавкаНДС_НеСопоставлена, СчётУчёта_НеОпределён, СуммаНеСходится.
- [ ] Если есть — разобрать каждую и устранить (см. [checklist_реакция_на_ошибку](checklist_реакция_на_ошибку.md)).
- [ ] Допустимо: STS_ОшибкаСервера / STS_ОшибкаСети (серверные проблемы STS не зависят от настройки БП).

## Шаг 8. Архивирование

- [ ] Сделать копию основных отчётов (ОСВ, карточки счетов) в архив за месяц.
- [ ] Записать в журнал: «Закрытие месяца N — итог сверка X ₽ — расхождение Y ₽».
- [ ] При необходимости — выгрузить дашборд формы «Загрузка из STS» в HTML (в меню «Ещё» → «Экспорт дашборда»).

## Шаг 9. Подготовка к новому месяцу

- [ ] Проверить что в каталоге OwnCloud не накопились старые файлы.
- [ ] Если есть подпапка `processed/` — переместить туда обработанные файлы (опционально, для гигиены каталога).
