# FAQ: Кнопка «Перезагрузить период»

Кнопка в форме «Загрузка из STS (топливо)» — универсальный backfill смен за выбранный период. Применяется когда нужно дозагрузить недостающие документы или перепровести существующие.

## Когда нужна

- В справочник видов оплат добавлен новый канал — нужно создать недостающие Перемещения для уже загруженных смен.
- Изменены счета учёта или другие настройки — нужно перепровести существующие документы по новой логике.
- Реализован новый kind (например, writeoff_fuel для pay_type=Прочие) — нужно догрузить эти строки для уже загруженных смен.

## Как открывается

1. Заполнить «Дата начала» и «Дата окончания» в форме.
2. По желанию — выбрать конкретную станцию в поле «Код станции» (0 = все станции).
3. Нажать кнопку **«Перезагрузить период»** в строке 1 командной панели.
4. Появится диалог с предпросмотром: «Найдено смен: N. Выберите действие».

## Три действия

| Кнопка диалога | Действие |
|---|---|
| **Да** | Дозагрузить недостающее — создать только отсутствующие подключи (Перемещения / ПКО / Списания). Существующие документы не трогаются. Дубли невозможны. **Безопасный режим.** |
| **Нет** | Перепровести существующие документы — записать каждый с проведением. Новые документы не создаются. Применяется при изменении настроек учёта. |
| **Отмена** | Отказ от операции. |

## Дозагрузить — типовой сценарий

Пример: в маппинг видов оплат добавлен канал voucher (талоны), а 63 смены за май уже загружены без него.

1. «Дата начала» = 01.05.2026, «Дата окончания» = 31.05.2026, «Код станции» = 0.
2. «Перезагрузить период» → «Да» (Дозагрузить).
3. Для каждой смены проверяется наличие Перемещения на склад «Талоны»:
   - Если есть — пропускается.
   - Если нет — создаётся.
4. Лог: «Смена 208/2456: +1 док.», «Смена 209/3801: +1 док.», итог «Создано: 63 документа, ошибок: 0».

## Перепровести — типовой сценарий

Пример: в учётной политике изменился счёт затрат — нужно перепровести Отчёты о розничных продажах за месяц.

1. Период и станция.
2. «Перезагрузить период» → «Нет» (Перепровести).
3. Для каждого документа из регистра TL_СтатусыЗагрузки за период:
   - Объект.Записать(РежимЗаписиДокумента.Проведение).
   - Лог: «Проведено: Отчёт о розн. продажах 0000123», «Проведено: …».
4. Документы пересчитают проводки по новой логике.

## Сбросить регистрацию периода

Отдельная кнопка в строке 1 — крайняя мера для редких случаев когда документы уже удалены вручную, а связь с центральной базой нужно очистить. См. [faq_дубль_пакета](faq_дубль_пакета.md).
