# FAQ: Документ не создался при загрузке пакета

В пакете присутствует строка документа, а в БП этот документ не появился.

## Где смотреть в первую очередь

1. Открыть **TradeLedger — Просмотр сверки пакетов**, найти пакет.
2. Колонка **Статус** — должна быть «ПринятоЧастично» или «Отклонено».
3. Нажать **«Показать ошибки пакета»** — откроется список причин.

## Типовые причины

### СправочникНеНайден (контрагент)
- Поставщик отсутствует в БП ГИГ.
- Действие: создать контрагента вручную (Покупки → Контрагенты → Создать) или дождаться автомаппинга по ИНН.

### СправочникНеНайден (номенклатура)
- Карточка товара отсутствует в БП ГИГ.
- Действие: создать вручную (Склад → Номенклатура → Создать) или дождаться автомаппинга по UUID.

### СправочникНеНайден (склад, организация, подразделение)
- Указанный в пакете элемент отсутствует.
- Действие: создать или поправить настройки обмена ([настройка_сопутки](настройка_сопутки.md) / [настройка_общепита](настройка_общепита.md)).

### ОтсутствуетОбязательноеПоле
- В пакете нет обязательного значения (например цена, дата, контрагент).
- Действие: проверить пакет в центральной базе, переформировать и перезагрузить.

### НеверныйТипДанных
- В поле передано не то значение (строка вместо числа, неверный формат даты).
- Действие: исправить в центральной базе. Скорее всего ошибка ввода данных оператором.

### ОшибкаЗапроса
- Внутренняя ошибка при поиске связанных объектов в БП.
- Действие: сообщить администратору расширения. Не пересматривать обычными средствами.

### ОшибкаПроведения
- Документ создан, но не проведён.
- Открыть документ из «Документы пакета», нажать **Провести**, прочитать ошибку.
- Действие: устранить причину (счета учёта, НДС, остаток на счёте 60.02 и т.п.) и провести вручную.

## Что делать после исправления

1. Если правка в БП (создан контрагент, поправлена номенклатура):
   - Открыть TradeLedger — Просмотр ошибок загрузки.
   - Найти строку ошибки → нажать **«Перезагрузить пакет»**.
   - Пакет переобрабатывается. Уже созданные документы обновляются, недостающие создаются.

2. Если правка в центральной базе (переформирован пакет):
   - Дождаться переформирования файла tl_*.json.
   - В TL_Загрузка нажать **«Опросить каталог»** — увидеть обновлённый файл.
   - **«Перезагрузить пакет»** в форме ошибок или повторная загрузка через TL_Загрузка.
