# Диагностика ошибок загрузки

Раздел: **ElsyPlus Ledger → Сервис → TradeLedger — Просмотр ошибок загрузки**.

Форма показывает записи регистра сведений **TL_ОшибкиЗагрузки** — все ошибки, возникшие при обработке пакетов.

## Состав записи об ошибке

| Поле | Содержит |
|---|---|
| ВремяРегистрации | Дата и время момента ошибки |
| ИдентификаторПакета | UUID пакета, в котором возникла ошибка |
| НомерЗаписи | Номер строки внутри пакета |
| ИсточникUUID | UUID объекта-источника |
| ТипОбъекта | Номенклатура / Контрагент / Поступление / Реализация и т.п. |
| Поле | Поле, на котором сработала ошибка |
| КодОшибки | Машиночитаемый код (см. [gloss_коды_ошибок](gloss_коды_ошибок.md)) |
| ЗначениеИсточника | Конкретное значение из пакета, вызвавшее ошибку |
| СообщениеОшибки | Текст ошибки в свободной форме |
| Документ | Ссылка на связанный документ, если есть |

## Фильтры

- **Дата начала / окончания** — период регистрации.
- **Фильтр тип объекта** — конкретный тип (например только ошибки по контрагентам).
- **Фильтр код ошибки** — конкретный код.
- **Фильтр идентификатор пакета** — ошибки одного пакета.

После изменения фильтров — **«Обновить»**. Сброс — **«Сбросить фильтры»**.

## Цветовая подсветка

- **Красный фон** — критичные ошибки (ОтсутствуетОбязательноеПоле, СправочникНеНайден, НеверныйТипДанных, ОшибкаЗапроса, ОшибкаПроведения). Загрузка прервана.
- **Серый фон** — предупреждения (ПродолженоПоУмолчанию, ИгнорированоПолитикой). Загрузка прошла с допущениями.

## Действия по строке

- **«Открыть пакет»** — переход в форму TradeLedger — Просмотр сверки пакетов с фильтром по выделенному пакету.
- **«Перезагрузить пакет»** — повторная загрузка JSON-файла пакета из настроенного каталога OwnCloud. Применяется после исправления маппинга или справочников в центральной базе.

## Типовой цикл обработки

1. Открыть форму, посмотреть фильтр за день.
2. Сортировка автоматическая по убыванию даты — свежие сверху.
3. По красным строкам — открыть пакет, найти исходную строку в центральной базе, исправить причину.
4. После исправления в центральной базе — нажать **«Перезагрузить пакет»**.
5. Новые ошибки появятся как новая запись с тем же пакетом — старые не удаляются автоматически (журнал событий).
