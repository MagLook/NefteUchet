# Сверка пакета — все ли пришло целиком

Раздел **TradeLedger → Сверка пакетов с источником** — журнал по каждому загруженному пакету.

## Что в форме

Список пакетов с колонками:

| Колонка | Что показывает |
|---|---|
| ИдентификаторПакета | Уникальный код пакета |
| ВремяЗагрузки | Когда пакет принят |
| Источник | Откуда пакет (ЦБ.Сопутка, ЦБ.Общепит, STS.Топливо) |
| ПериодС / ПериодПо | Период данных в пакете |
| СтрокНСИ | Сколько записей справочников |
| СтрокДокументов | Сколько строк документов |
| СуммаЦБ | Сумма по данным центральной базы |
| СуммаБП | Сумма по созданным документам |
| Расхождение | СуммаБП − СуммаЦБ |
| Статус | ПринятоЦеликом / ПринятоЧастично / Отклонено |
| Ошибок | Количество ошибок по этому пакету |
| ДоктовБП | Сколько документов создалось |

## Цветовая палитра строк

- **Светло-зелёный** — Статус «ПринятоЦеликом». Идеальное состояние.
- **Светло-жёлтый** — «ПринятоЧастично». Часть строк не обработана.
- **Светло-красный** — «Отклонено». Пакет не загружен или загружено меньше половины.
- **Красный** в колонке Расхождение — расхождение > 0.01 ₽.

## Итоги вверху

В заголовке формы показывается за выбранный период:
- Найдено пакетов с разбивкой по статусам.
- Итого сумма ЦБ, сумма БП, расхождение.

Удобно копировать в отчёт за день/месяц.

## Действия по строке

### «Показать ошибки пакета»

Открывает форму **TradeLedger → Журнал ошибок загрузки** с фильтром по выделенному пакету. Видно по каким строкам были проблемы.

### «Документы пакета»

Открывает список всех документов созданных по этому пакету (через TL_СоответствиеИсточников). Двойной клик по строке — откроется документ в БП.

## Типовой цикл проверки

### Утром после загрузки

1. Открыть форму, период — «Вчера».
2. Все строки зелёные → проверка пройдена.
3. Жёлтые → открыть «Показать ошибки пакета», см. [реакция_на_ошибку](реакция_на_ошибку.md). Устранить причину и нажать **«Перезагрузить период»** → **«Да»** в форме «Загрузка из STS».
4. Красные → срочно разобрать. Возможно недоступен каталог OwnCloud или серьёзная ошибка центральной базы.

### При закрытии месяца

1. Период — весь месяц.
2. Все пакеты должны быть «ПринятоЦеликом» или «ПринятоЧастично» с понятным комментарием.
3. Итоговая сумма расхождения должна быть приемлемая (округления — да; значимое расхождение — нет).

## Типовые сложности

### Пакет в списке отсутствует

Если файл tl_*.json есть в каталоге, но в сверке нет записи — значит обработка ещё не запускалась.

- В форме «Загрузка из STS» в меню «Ещё» → «Опросить каталог» → загрузить вручную.

### «ПринятоЧастично» из-за маппинга

Категория ошибки **МаппингОплат_НеНайден** (фиолетовый). См. [реакция_на_ошибку](реакция_на_ошибку.md) → раздел «Маппинг оплат не найден».

### «ПринятоЧастично» из-за НСИ

Категория **НСИ_НеНайдена** (бирюзовый). Не найден контрагент / номенклатура. Создать недостающее в БП, перезагрузить.

### Расхождение копеечное

Округление при пересчёте НДС. Записать в комментарий пакета и не разбираться.

### Расхождение значимое

См. [расхождение_в_сверке](расхождение_в_сверке.md).
