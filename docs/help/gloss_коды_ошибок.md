# Глоссарий: коды ошибок загрузки

Поле **КодОшибки** в регистре TL_ОшибкиЗагрузки — значение перечисления **TL_КодОшибкиЗагрузки**.

## Критичные коды

Документ не создан, требуется устранение причины и перезагрузка пакета.

### ОтсутствуетОбязательноеПоле
- В пакете нет значения для обязательного поля (например цена, дата, контрагент, склад).
- Причина: некорректное формирование пакета в центральной базе.
- Действие: переформировать пакет в центральной базе.

### СправочникНеНайден
- Указанный в пакете элемент справочника (контрагент, номенклатура, склад, организация и т.п.) не существует в БП ГИГ.
- Действие: создать карточку или настроить автомаппинг по ИНН/UUID. См. [faq_неизвестный_контрагент](faq_неизвестный_контрагент.md).

### НеверныйТипДанных
- В поле передано значение неверного типа (строка вместо числа, неверный формат даты, отрицательное количество).
- Действие: исправить в центральной базе.

### ОшибкаЗапроса
- Внутренняя ошибка при выполнении запроса к БД.
- Действие: сообщить администратору расширения. Самостоятельно не диагностируется.

### ОшибкаПроведения
- Документ создан, но при проведении возникла ошибка БП (например недостаточно остатка для списания, неверный счёт учёта, нарушение учётной политики).
- Действие: открыть документ через «Документы пакета», нажать «Провести» вручную, прочитать сообщение об ошибке БП, устранить.

## Предупреждения

Документ создан, но с допущениями. В сверке строка обычно зелёная или жёлтая.

### ПродолженоПоУмолчанию
- В пакете не было обязательного значения, использовано значение по умолчанию из настроек обмена.
- Например: подразделение не указано — взято из настроек.
- Действие: проверить что значение по умолчанию подходит. Если нет — поправить в центральной базе.

### ИгнорированоПолитикой
- Строка пакета намеренно пропущена согласно настройкам обмена.
- Например: канал оплаты «coupon» — игнорируется (купоны не отражаются в БП ГИГ).
- Действие: ничего, это штатное поведение.

## Информационные

Никакого действия не требуется.

### Информация
- Внутренние сообщения о ходе обработки.
- Действие: используются для отладки, бухгалтером не разбираются.
