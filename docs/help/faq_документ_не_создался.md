# FAQ: Документ не создался при загрузке пакета

В пакете присутствует строка документа, а в БП этот документ не появился.

## Где смотреть в первую очередь

1. В форме «Загрузка из STS» нажать **«Подробный отчёт ошибок»**.
2. Открывшийся отчёт показывает причины сгруппированные по категориям.
3. Альтернативно — открыть **TradeLedger → Сверка пакетов с источником**, найти пакет, нажать «Показать ошибки пакета».

## Типовые причины

### МаппингОплат_НеНайден

- В STS пришёл новый вид оплаты, для которого нет записи в маппинге.
- Действие: открыть **TradeLedger → Маппинг видов оплат STS**, создать запись с образцом имени из колонки «Значение» в отчёте.

### НСИ_НеНайдена (контрагент)

- Поставщик отсутствует в БП ГИГ.
- Действие: создать контрагента вручную (Покупки → Контрагенты → Создать) или дождаться автомаппинга по ИНН.

### НСИ_НеНайдена (номенклатура)

- Карточка товара отсутствует в БП ГИГ.
- Действие: создать вручную (Справочники → Номенклатура → Создать) или дождаться автомаппинга по UUID.

### НСИ_НеНайдена (склад, организация, подразделение)

- Указанный в пакете элемент отсутствует.
- Действие: создать или поправить настройки обмена ([настройка_сопутки](настройка_сопутки.md) / [настройка_общепита](настройка_общепита.md)).

### ОбязательноеПолеПусто

- В пакете нет обязательного значения (цена, дата, контрагент).
- Действие: проверить пакет в центральной базе, переформировать и перезагрузить.

### СтавкаНДС_НеСопоставлена

- В пакете передана неизвестная ставка НДС.
- Действие: сообщить обслуживающей организации с указанием значения.

### ВидОперацииНеСопоставлен

- В пакете передан вид операции которая ещё не покрыта связкой.
- Действие: сообщить обслуживающей организации с указанием кода.

### ОшибкаПроведения

- Документ создан, но не провёлся.
- Открыть документ через колонку «Пакет» в журнале сверки, нажать «Провести» в БП, прочитать ошибку.
- Действие: устранить причину (счета учёта, НДС, остаток на счёте 60.02 и т.п.) и провести вручную.

### STS_ОшибкаСервера / STS_ОшибкаАвторизации / STS_ОшибкаСети

- Источник не вернул данные сменного отчёта.
- Это не настройка БП — серверная или сетевая проблема.
- Действие: см. [checklist_реакция_на_ошибку](checklist_реакция_на_ошибку.md).

### Прочее

- Внутренняя ошибка не покрытая категориями.
- Действие: сообщить обслуживающей организации, не пытаться разобрать самостоятельно.

## Что делать после исправления

1. Если правка в БП (создан контрагент, поправлена номенклатура):
   - В форме «Загрузка из STS» нажать **«Перезагрузить период»** → выбрать **«Да» (Дозагрузить)**.
   - Будут созданы только недостающие документы. Дубли невозможны.
   - Дождаться завершения, проверить «Подробный отчёт ошибок» — ошибка исчезла.

2. Если правка в центральной базе (переформирован пакет):
   - Дождаться переформирования файла tl_*.json (обычно несколько минут).
   - В меню «Ещё» нажать «Опросить каталог» — увидеть обновлённый файл.
   - **«Перезагрузить период»** → **«Да» (Дозагрузить)**.
