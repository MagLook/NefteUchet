# Расхождение в сверке пакета

В форме **TradeLedger → Сверка пакетов с источником** колонка **Расхождение** показывает разницу: «Сумма БП − Сумма ЦБ».

Если значение больше 0.01 ₽ по модулю — колонка подсвечена красным.

## Возможные причины

### Округление при пересчёте

Цена с НДС в центральной базе и цена без НДС с раздельным НДС в БП могут давать разницу в копейках.

- Допустимое значение: до нескольких рублей на пакет с сотнями строк.
- **Что делать:** записать в комментарий пакета «округление НДС», не разбираться дальше.

### Пропущенная строка из-за ошибки

В пакете была строка которую не удалось обработать.

- Признак: в подробном отчёте ошибок есть категории по этому пакету.
- **Что делать:** устранить причину (см. [реакция_на_ошибку](реакция_на_ошибку.md)), нажать **«Перезагрузить период»** → **«Да» (Дозагрузить)**.

### Двойной учёт

Пакет загружен дважды разными путями (автомат + вручную) или документ создан вручную в БП до прихода пакета.

- Признак: в БП больше документов чем должно быть.
- **Что делать:** найти лишний документ, проверить через регистр **TL_СоответствиеИсточников** какие пакеты привязаны, удалить лишний документ вручную.

### Изменение в центральной базе после выгрузки

Документ изменили в центральной базе уже после формирования пакета.

- **Что делать:** переформировать пакет в центральной базе → дождаться нового файла → **«Перезагрузить период»** → **«Да»**.

### Разная учётная политика по НДС

Центральная база работает с НДС 22%, в БП в карточке номенклатуры стоит 20% или Без НДС.

- **Что делать:** согласовать ставки. Поправить карточку номенклатуры в БП или попросить технолога передавать с правильной ставкой.

## Что делать при первом обнаружении

1. Открыть пакет в сверке.
2. Проверить колонку «Ошибок» — если есть, начать с них.
3. Открыть «Документы пакета» → посмотреть документы → сравнить с центральной базой.
4. Если документ создан но сумма отличается — открыть документ, посмотреть проводки через Дт/Кт.
5. Если расхождение копеечное — записать в комментарий причину и оставить.
6. Если расхождение значимое — устранить, перезагрузить.

## Когда срочно сообщать обслуживающей организации

- Расхождение > 100 ₽ на одном пакете.
- Расхождение в нескольких пакетах подряд по одному поставщику.
- Расхождение по налоговым счетам (68.02, 19.03).
- Расхождение постоянно растёт от пакета к пакету.

В этих случаях — приостановить автоматическое проведение до выяснения причины.
