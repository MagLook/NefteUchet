# С чего начать новому сотруднику

Если вы первый раз открыли расширение TradeLedger — прочитайте эту статью. На неё уйдёт 10 минут.

## Что такое TradeLedger

Это «помощник бухгалтера» внутри 1С Бухгалтерии. Он сам:

1. **Каждое утро забирает с АЗС** данные о продажах за вчера: топливо, сопутка (чипсы, вода), общепит (кофе, выпечка).
2. **Сам создаёт документы** в 1С — Отчёт о розничных продажах, Поступление от поставщика, и т.д.
3. **Сам формирует проводки** — Дт/Кт по нужным счетам.

Бухгалтеру остаётся:
- **Проверить** что всё пришло (нет пропавших смен).
- **Реагировать на ошибки** если они появились (например, новый поставщик которого нет в базе).
- **Закрывать месяц** обычным порядком в БП.

## Где находится расширение

В левой панели разделов 1С:Предприятия — раздел **TradeLedger** (рядом с «Покупки», «Продажи», «Банк и касса»).

В этом разделе 8 пунктов:

| Пункт | Что делает |
|---|---|
| **Загрузка из STS (топливо)** | Главная форма — отсюда работают каждый день |
| Загрузка пакетов из ЦБ (сопутка/общепит) | Альтернативный вход для сопутки и общепита |
| Журнал ошибок загрузки | Что-то пошло не так — смотрите сюда |
| Сверка пакетов с источником | Все ли пакеты пришли с АЗС |
| Маппинг видов оплат STS | Настройка соответствий каналов оплат (редко) |
| Настройки обмена общепита | Настройки приёма блюд (редко) |
| Настройки обмена сопутки | Настройки приёма сопутки (редко) |
| Настройки расширения | Общие параметры (редко) |

## Что делать сразу

### Шаг 1. Откройте главную форму

**TradeLedger → Загрузка из STS (топливо)**

Что увидите:
- Вверху — четыре цветные плашки **KPI**: количество смен, ошибки, новые смены, выручка.
- Слева — служебный лог сегодняшних действий.
- Посередине — поля для выбора периода и кода АЗС.
- Кнопки: **Обновить** | **Перезагрузить период** | **Подробный отчёт ошибок** | **Помощь**.
- Ниже — две таблицы: слева уже загруженные документы, справа — внешние данные с АЗС.

### Шаг 2. Нажмите «Обновить»

Появятся данные за выбранный период. Если за сегодня уже были смены — они появятся справа.

### Шаг 3. Нажмите «Подробный отчёт ошибок»

Откроется отдельное окно. Если ошибок нет — увидите зелёное «✓ Ошибок нет» и журнал того что происходило сегодня. Это норма.

### Шаг 4. Нажмите «Помощь»

Откроется это содержание — отсюда можете перейти к любой нужной статье.

### Шаг 5. Прочитайте про ежедневный сценарий

Откройте [ежедневный_приём](ежедневный_приём.md) — там пошагово что делать утром и в течение дня.

## Что НЕ нужно делать

- ❌ **Не вводите вручную** Отчёты о розничных продажах за АЗС-смены — их создаёт расширение.
- ❌ **Не вводите вручную** Поступления от поставщиков по АЗС — приходят пакетом.
- ❌ **Не вводите вручную** Выпуск блюд — теперь не нужен (см. [общепит_что_изменилось](общепит_что_изменилось.md)).

Дублирование вручную создаст лишние документы, и сверка с АЗС не сойдётся.

## Что делать если страшно нажимать кнопки

- Кнопка **«Перезагрузить период»** → выбор **«Да» (Дозагрузить)** — безопасная. Дубли невозможны.
- Кнопка **«Сбросить регистрацию»** (в выпадающем меню «Ещё») — опасная, требует двойного подтверждения. Без необходимости не нажимать.
- Любая кнопка в форме настройки → **«Сохранить»** — только когда уверены. Иначе закрыть форму без сохранения (Esc).

## Что делать если непонятно

- Кнопка **«Помощь»** — оглавление 30+ статей в этой справке.
- В подробном отчёте ошибок рядом с каждой категорией есть ссылка **«📖 Подробнее»** — открывает статью именно про эту ошибку.
- Если в статье встретилось непонятное слово — посмотрите в [словарь_терминов](словарь_терминов.md).
- Если справка не помогла — обратиться к обслуживающей организации с указанием:
  - Какая операция выполнялась.
  - Какой документ открыт (если есть).
  - Какая ошибка появилась (скриншот из «Подробный отчёт ошибок»).
