# Первая настройка после установки расширения

Один раз — после установки расширения TradeLedger в БП ГИГ. Обычно делает обслуживающая организация совместно с главным бухгалтером.

## Предусловия

- Расширение TradeLedger накачено в БП ГИГ через Конфигуратор.
- Обновление БД (F7) выполнено.
- В БП ГИГ заведена организация ГАЗИНВЕСТГРУПП с ИНН 7839440090.
- Согласован путь каталога OwnCloud с обслуживающей организацией.

## Шаг 1. Базовая инфраструктура в БП

Проверить наличие в БП ГИГ:

- [ ] Организация ГАЗИНВЕСТГРУПП (Главное → Организации).
- [ ] У организации заполнены ИНН, КПП, юридический адрес, банковские реквизиты.
- [ ] В справочнике Подразделения организаций есть подразделение для АЗС с «208» в наименовании.
- [ ] В справочнике Склады заведён склад с «208» в наименовании.
- [ ] В справочнике Контрагенты есть НОРД-ЛАЙН с ИНН 7804572748.
- [ ] В справочнике Статьи движения денежных средств есть «Розничная выручка».
- [ ] В справочнике Виды оплат организаций есть «Платежная карта».
- [ ] В справочнике Статьи затрат есть «Списание материалов».
- [ ] В справочнике Номенклатурные группы есть «Общепит» или «Производство».

## Шаг 2. Заполнить настройки по умолчанию

1. Открыть **TradeLedger → Настройки расширения**.
2. Нажать кнопку **«Заполнить настройки по умолчанию»**.

Что произойдёт:
- Создаётся 20 записей маппинга видов оплат STS — все виды оплат сети ГИГ (включая Газпромнефть, Мосресурс, Прочие, талоны).
- Создаётся 6 каналов оплат: retail / cards / online / ledger / voucher / writeoff_fuel.
- Заполняются 12 АЗС сети ГИГ с привязкой к складам.
- Заполняются базовые параметры подключения к STS API.
- Устанавливается модель учёта общепита B (новая, через ингредиенты).

Прочитать журнал — должно быть сообщение «Создано N настроек, M маппингов, K станций».

**Идемпотентно** — нажатие повторно не перезаписывает уже изменённые значения.

## Шаг 3. Настройка обмена Сопутки

1. **TradeLedger → Настройки обмена сопутки**.
2. Нажать «Заполнить по умолчанию».
3. Проверить значения: организация, контрагент, склад, подразделение.
4. Заполнить «Каталог OwnCloud» — путь согласованный с обслуживающей организацией.
5. Нажать «Проверить каталог» — должно сообщить количество файлов tl_*.json (вначале обычно 0).
6. Установить флаг «Проводить автоматически» — да.
7. «Сохранить настройки».

## Шаг 4. Настройка обмена Общепита

1. **TradeLedger → Настройки обмена общепита**.
2. Нажать «Заполнить по умолчанию».
3. Проверить значения: организация, подразделение, счета 44.01 / 41.02, статья затрат, номенклатурная группа.
4. Если номенклатурная группа не подобралась — выбрать вручную.
5. Установить флаг «Проводить автоматически».
6. «Сохранить настройки».

## Шаг 5. Базовая проверка

1. **TradeLedger → Загрузка из STS (топливо)** — дашборд показывает «STS подключено».
2. Переключить режим на «Сопутка» (через меню «Ещё») → дашборд показывает «Канал доступен».
3. То же для режима «Общепит».
4. **TradeLedger → Сверка пакетов с источником** → пусто (пакетов ещё не было) → форма открылась без ошибок.
5. **TradeLedger → Журнал ошибок загрузки** → пусто → форма открылась.
6. В форме «Загрузка из STS» нажать «Помощь» → открылось оглавление справки.

## Шаг 6. Тестовый пакет

1. Получить от центральной базы тестовый пакет (1-2 строки).
2. Положить файл tl_*.json в каталог обмена.
3. В форме «Загрузка из STS» в меню «Ещё» → «Опросить каталог» → должен показать 1 новый файл.
4. «Обновить» → файл появляется во внешней таблице.
5. Загрузить → проверить что документ создался.
6. Открыть документ → проверить проводки (Дт/Кт).

## Шаг 7. Передача в работу

- Показать бухгалтеру раздел **TradeLedger** в левой панели — 8 пунктов меню.
- Показать кнопку «Помощь» — встроенная справка.
- Пройтись по статье [с_чего_начать_новому_сотруднику](с_чего_начать_новому_сотруднику.md).
- Договориться о времени первой совместной загрузки реального пакета.
