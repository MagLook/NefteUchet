# Настройка обмена общепита

Раздел: **TradeLedger → Настройки обмена общепита (ЦБ → БП)**.

Форма задаёт параметры приёма пакетов общепита (блюда, ингредиенты) из центральной базы.

## В модели B (с 22.05.2026)

С новой методики учёта общепита эта форма имеет **ограниченное значение**:
- Документы ОПЗС больше **не создаются** (см. [общепит_что_изменилось](общепит_что_изменилось.md)).
- Продажи блюд попадают в ОРП Сопутки с раскладкой на ингредиенты.

Однако настройки сохраняются для обратной совместимости и на случай возврата к модели A.

## Первичная настройка

1. **TradeLedger → Настройки обмена общепита (ЦБ → БП)**.
2. Кнопка **«Заполнить по умолчанию»**:
   - Организация — ГАЗИНВЕСТГРУПП.
   - Подразделение — с «208» в наименовании.
   - Счёт затрат — **44.01** (издержки общепита). Не используется в модели B.
   - Счёт готовой продукции / сырья — **41.02** (товары в рознице).
   - Статья затрат — «Списание материалов».
   - Номенклатурная группа — «Общепит» / «Производство» (если существует).
3. Проверить подобранные значения. Особенно — Номенклатурная группа. Если не подобралась — выбрать вручную или создать в справочнике.
4. Заполнить **«Каталог OwnCloud»** (общий с Сопуткой).
5. Установить флаг «Проводить автоматически» — да.
6. **«Сохранить настройки»**.

## Что хранится

Параметры лежат в регистре **TL_Настройки** под ключами с префиксом «Общепит_». Дополнительно — ключ **«Общепит_МодельУчёта»** = "B" (по умолчанию) или "A" (legacy).

## Особенности счетов учёта (для модели A)

- **41.02** — «Товары в розничной торговле (в НТТ по продажной стоимости)». На него приходовалось сырьё и готовая продукция.
- **44.01** — «Издержки обращения». Через него проходили затраты по выпуску блюд.

В модели B оба счёта не используются для движений общепита — себестоимость уходит сразу через 90.02.1.

## Когда повторно настраивать

- При смене каталога обмена.
- При смене основной организации.
- При замене подразделения или счетов учёта.
