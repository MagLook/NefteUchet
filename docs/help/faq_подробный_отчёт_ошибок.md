# FAQ: Кнопка «Подробный отчёт ошибок»

Кнопка в форме «Загрузка из STS (топливо)» — открывает полноэкранный диагностический отчёт по всем ошибкам загрузки за сегодня плюс лог текущей сессии.

## Когда нужна

- После загрузки появилась запись «Ошибка» в логе сессии — открыть отчёт чтобы увидеть категорию и понять что делать.
- После каждой загрузки за день — проверить нет ли скрытых ошибок которые не отображались в журнале формы.
- Перед закрытием месяца — финальная проверка что все загрузки прошли без проблем.

## Как открывается

Кнопка **«Подробный отчёт ошибок»** в строке 1 командной панели формы. Открывается отдельное окно во весь экран.

Окно открывается всегда — даже если ошибок нет. В этом случае выводится «✓ Ошибок нет» и крупный лог текущей сессии.

## Структура отчёта

### Верхняя часть — отчёт ошибок

Если ошибки есть — они сгруппированы по категориям с цветовой палитрой:

| Цвет | Категория |
|---|---|
| Жёлтый | Серверные ошибки STS (HTTP 5xx) |
| Красный | Ошибка авторизации, ошибка проведения |
| Синий | Сетевая ошибка |
| Фиолетовый | Маппинг видов оплат / Вид операции не сопоставлен |
| Бирюзовый | НСИ не найдена / ставка НДС / счёт учёта |
| Серый | Прочее |

Для каждой категории выводится:
- Иконка, заголовок, счётчик ошибок.
- Блок «Что делать» — пошаговая инструкция.
- Ссылка «📖 Подробнее» — открывает соответствующую статью встроенной помощи.
- Таблица с колонками: Время, Пакет, Значение, Сообщение.

### Нижняя часть — лог текущей сессии

Тёмный фон, моноширинный шрифт. Сюда попадают все сообщения которые форма выводила в журнал за время текущего сеанса работы:
- «Обновление данных…», «Внешних: N, в 1С: M».
- «Загрузка N документов…», результат каждой смены.
- «Перезагрузка периода: …», прогресс.
- Сообщения об ошибках с их типом (HTTP 500, авторизация, сеть).

## Если ошибок нет

Окно открывается, в верхней части — зелёная плашка «✓ Ошибок нет». Это норма — значит за сегодня все загрузки прошли без проблем.

Нижняя часть с логом полезна сама по себе: можно увидеть какие смены загружались, когда, сколько новых документов создано.
