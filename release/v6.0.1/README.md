# TradeLedger v6.0.1 — hotfix к v6.0.0

**Дата:** 2026-05-14
**Файл:** `TradeLedger.cfe` (~144 КБ)
**База назначения:** БП ГИГ (192.168.40.31), Бухгалтерия предприятия 3.0, режим совместимости 8.3.24

## Главный фикс: опечатка ломала автозаливку маппинга оплат

В v6.0.0-alpha процедура `TL_Маппинг.ЗаполнитьМаппингОплатПоУмолчанию()` (строка 540 модуля) вызывала **несуществующую** функцию `TL_Настройки.УстановитьЗначениеПоУмолчаниюГИГ()`. Правильное имя — `ИнициализироватьПоУмолчаниюГИГ()`.

**Симптом на проде:** при нажатии «Сохранить» в форме настроек TradeLedger маппинг оплат не заполнялся, регистр `TL_МаппингОплат` оставался пустым. При попытке загрузить смену в логе появлялось «Ошибка: Не настроен маппинг для видов оплат: "Наличные", "Купон на сдачу", "Сбе..."», документы не создавались. Вызов был обёрнут в `Попытка...Исключение` без логирования, поэтому ошибка незаметна.

## Что изменено

1. **`src/CommonModules/TL_Настройки.bsl`** — выделил блок заливки 15 образцов маппинга оплат в отдельную **экспортную** процедуру `ЗаполнитьТолькоМаппингОплат()`. `ИнициализироватьПоУмолчаниюГИГ()` теперь вызывает её внутри — поведение полной инициализации сохранено.
2. **`src/CommonModules/TL_Маппинг.bsl:540`** — заменил вызов на корректный `TL_Настройки.ЗаполнитьТолькоМаппингОплат()`. **Важная разница**: новая процедура заполняет **только** маппинг и не перетирает остальные настройки (URL/Логин/Топливо/Каналы) при каждом нажатии «Сохранить».
3. **`xml-v4/Configuration.xml`** — версия 6.0.0-alpha → **6.0.1**.

## Что НЕ изменено (умышленно)

- Discovery станций (`Загрузить станции из API`) работает корректно. Если на проде сейчас видна только одна станция АКЗС Витебский (5) — это потому что **кнопка «Загрузить станции из API» не была нажата**. После накатки v6.0.1 — нужно нажать её вручную, и подтянутся все станции сети 65.
- Состав 15 образцов маппинга идентичен v6.0.0: наличн / сбербанк / viacard / балтоп / baltop / корпоратив / топливн / агора / яндекс / мобил / benzuber / ведомост / талон / купон / прокач.
- Все остальные правки v6.0.0 (разноска VIAcard/БАЛТОП в Перемещения, склад «Талоны», прочерки в денежных колонках безналичных, защита от незнакомых видов оплат) сохранены.

## Как накатить на боевую БП ГИГ

1. **Бэкап БП ГИГ** через Конфигуратор: Администрирование → Выгрузить информационную базу → сохранить `.dt`-файл.
2. В Предприятии: **Администрирование → Печатные формы, отчёты и обработки → Расширения конфигурации**.
3. Кликнуть на строку **TradeLedger** → **Удалить** (данные регистров TL_Настройки, TL_МаппингОплат, TL_СтатусыЗагрузки **сохранятся**).
4. **Добавить из файла** → выбрать новый `TradeLedger.cfe` v6.0.1.
5. Главное меню → Сервис → **Перезапустить** (или просто закрыть и заново открыть 1С).

## Чек-лист после накатки

- [ ] **Меню ElsyPlus Ledger** в боковом меню видно
- [ ] Открыть **«Настройка расширения TradeLedger»** → пройти все шаги до конца → нажать **«Сохранить настройки»**
- [ ] Открыть **«Маппинг видов оплат STS на каналы и склады»** → **15 строк** (раньше было 0). У VIAcard/БАЛТОП/корпоратив/топливн/агора/baltop колонка «Склад» = «Карты». У яндекс/мобил/benzuber = «ЯНДЕКС». У ведомост = «Ведомости». У талон = «Талоны». У наличн/сбербанк — пусто (это розница). У купон/прокач — пусто (игнор)
- [ ] Если склада «Талоны» нет в Catalog.Склады — завести вручную (Тип = Оптовый)
- [ ] В «Настройка расширения TradeLedger» → шаг «Станции АЗС → Склады 1С» → нажать **«Загрузить станции из API»** → подтянутся все 12 станций сети 65. Проверить привязки к складам (АКЗС Витебский (5), АЗС Светогорск (8), и т.д.)
- [ ] Сохранить настройки ещё раз
- [ ] Открыть **«Загрузка из TradeLedger»** → отметить любую свежую смену → **«Загрузить выбранные»**
- [ ] В созданном ОРП — товарная часть только наличные + Сбербанк. Если в смене был VIAcard/БАЛТОП — создано Перемещение на «Карты». ПКО на наличные

## Откат

Если что-то пошло не так:
1. В Предприятии: Администрирование → Расширения конфигурации → TradeLedger → Удалить.
2. Восстановить из бэкапа `.dt` (Администрирование → Загрузить информационную базу) — для отката данных, если расширение успело что-то записать.
3. Установить предыдущую версию `TradeLedger.cfe` из `release/v6.0.0/`.
