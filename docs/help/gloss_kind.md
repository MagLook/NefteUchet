# Глоссарий: kind пакета

**kind** — тип пакета, определяет какой документ и какие проводки будут созданы в БП. Указывается в заголовке файла tl_*.json.

## Активные kind

| kind | Описание | Документ БП | Раздел |
|---|---|---|---|
| `purchase` | Поступление товаров от поставщика | ПоступлениеТоваровУслугНаАЗК (ПТУ) | Сопутка |
| `retail_sale_sidegoods` | Розничная продажа сопутствующих товаров | ОтчётОРозничныхПродажах (ОРП) | Сопутка |
| `production_release` | Выпуск блюд + списание сырья за смену | ОтчётПроизводстваЗаСмену (ОПЗС) | Общепит |
| `return_purchase` | Возврат поставщику / корректировка поступления | КорректировкаПоступления | Сопутка |

## Подробности

### purchase
- Источник: документ Поступление в центральной базе.
- Состав: товары + услуги + транспорт.
- Проводки: 41.02/60.01 + 19.03/60.01 + автозачёт 60.02/60.01.
- См. [проводки_покупки](проводки_покупки.md).

### retail_sale_sidegoods
- Источник: сменный отчёт ККМ из центральной базы, отфильтрованный по сопутствующим товарам.
- Состав: товары + расшифровка платежей (нал/безнал/карты).
- Проводки: 90.02.1/41.02 + 62.Р/90.01.1 + 57.03/62.Р + 50.01/62.Р + 90.03/68.02.
- См. [проводки_сопутки](проводки_сопутки.md).

### production_release
- Источник: ВыпускПродукции в центральной базе.
- Состав: продукция (выпущенные блюда) + материалы (списанные ингредиенты).
- Проводки: 41.02/44.01 (выпуск) + 44.01/41.02 (списание).
- См. [проводки_общепита](проводки_общепита.md).

### return_purchase
- Источник: возврат или корректировка поступления в центральной базе.
- Состав: позиции с новыми (откорректированными) значениями.
- Проводки: обратные относительно оригинального ПТУ.
- См. [проводки_корректировки](проводки_корректировки.md).

## Будущие kind (планируются)

Существуют пакеты других типов, которые в текущей версии не приходят, но зарезервированы в коде:
- `inventory` — инвентаризация
- `writeoff` — списание
- `transfer` — перемещение между складами
- `cash_in` / `cash_out` — кассовые операции (помимо ОРП)

При появлении таких пакетов — описание добавится сюда.
