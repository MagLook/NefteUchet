# Настройка обмена: Сопутка

Раздел: **TradeLedger → Настройки обмена сопутки (ЦБ → БП)**.

Форма задаёт параметры приёма пакетов сопутствующих товаров из центральной базы ЭЛСИ.АЗК.

## Чек-лист первичной настройки

1. Открыть форму **TradeLedger → Настройки обмена сопутки (ЦБ → БП)**.
2. Нажать **«Заполнить по умолчанию»** — значения подбираются автоматически:
   - Организация — ГАЗИНВЕСТГРУПП по ИНН 7839440090
   - Контрагент-источник — НОРД-ЛАЙН по ИНН 7804572748
   - Склад — первый склад, содержащий «208» в наименовании
   - Подразделение — первое подразделение организации, содержащее «208» в наименовании
   - Статья ДДС — «Розничная выручка»
   - Вид оплаты — «Платежная карта»
3. Проверить подобранные значения. При необходимости откорректировать вручную.
4. Заполнить **«Каталог OwnCloud»** — путь к каталогу обмена с центральной базой (см. [настройка_каталога](настройка_каталога.md)).
5. Нажать **«Проверить каталог»** — журнал должен сообщить количество файлов tl_*.json в каталоге.
6. Установить флаг **«Проводить автоматически»** — да (рекомендуется).
7. Нажать **«Сохранить настройки»** — в журнале появится подтверждение.

## Контроль настройки

Все параметры хранятся в регистре сведений **TL_Настройки** под ключами с префиксом **«Сопутка_»**.

Для повторного открытия формы — нажать **«Загрузить настройки»**. Значения подтянутся из регистра.

## Когда повторно настраивать

- При смене каталога обмена с центральной базой.
- При смене основной организации в БП.
- При замене подразделения, склада, контрагента или статьи ДДС.
- При переходе следующей АЗС с прежней организации на ГАЗИНВЕСТГРУПП — после Дня X.
