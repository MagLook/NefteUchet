# Эталонная конфигурация TradeLedger на боевой БП ГИГ (21.05.2026)

Скриншоты из продуктивной базы `192.168.40.31` → база `ГазИнвестГрупп ООО 2018`.
Использовать как **источник правды для настроек по умолчанию** в следующей версии
расширения (процедуры `TL_Настройки.ЗаполнитьМаппингОплатПоУмолчанию` и аналогов).

## 1. Справочник `TL_ВидыОплат` — каналы оплат и их виртуальные склады

| Наименование | Код внешний | Склад | Требует перемещения | Контрагент |
|---|---|---|---|---|
| Розница (наличные + эквайринг) | `retail` | — | ☐ | — |
| Топливные карты | `cards` | Карты | ☑ | — |
| Онлайн (Яндекс, МобилПр.) | `online` | ЯНДЕКС | ☑ | — |
| Ведомости | `ledger` | Ведомости | ☑ | — |
| **Талоны** | `voucher` | **Талоны** | **☑** | — |

**Замечания для версии по умолчанию:**
- `retail` — без склада и без перемещения (это розничная выручка → ОРП).
- Все остальные каналы — с галкой «Требует перемещения» и заполненным виртуальным складом.
- Поле `Контрагент` — пусто для всех (закрытие через ручную Реализацию по факту).

## 2. Регистр `TL_МаппингОплат` — соответствие имени STS → каналу

Поиск по подстроке через `НРег(ОбразецИмени)`. Образцы должны покрывать
все варианты имён `pay_type.name` из STS API.

| Образец имени (НРег) | Канал | Склад (переопределение) | Комментарий |
|---|---|---|---|
| `baltop` | cards | Карты | топливные карты БАЛТОП лат. |
| `benzuber` | online | ЯНДЕКС | онлайн-заказы Benzuber |
| `viacard` | cards | Карты | топливные карты VIAcard |
| `агора` | cards | Карты | агрегатор «Агора» |
| `балтоп` | cards | Карты | БАЛТОП кириллица |
| `ведомост` | ledger | Ведомости | по ведомостям |
| `Инфорком` | cards | Карты | топливные карты Инфорком (добавлено 21.05.2026) |
| `корп.карты` | cards | Карты | общая категория корпкарт |
| `корпоратив` | cards | Карты | корпоратив |
| `купон` | (пусто) | (пусто) | игнорируется (купоны на сдачу) |
| `мобил` | online | ЯНДЕКС | мобильные приложения |
| `наличн` | retail_cash | — | наличная выручка |
| `прокач` | (пусто) | (пусто) | техпрокачка (заправка собственного транспорта) |
| `сбербанк` | retail_card | — | банковский эквайринг |
| `талон` | voucher | **Талоны** | топливные талоны (добавлено 21.05.2026) |
| `топливн` | cards | Карты | общая «топливные» |
| `яндекс` | online | ЯНДЕКС | Яндекс Заправки |

**Замечания для версии по умолчанию:**
- Поиск через `СтрНайти(имя_из_STS, ОбразецИмени) > 0` — образцы должны быть в нижнем регистре, корнями (например `талон` ловит «Талоны», «талонная», «по талону»).
- **Не покрыто (надо решить):** `pay_type.name="прочие"` — техсписания топлива (ДТ при разливе, испарение). Сейчас падает с ошибкой «не настроен маппинг». Варианты:
  - оставить пустым (игнорировать как купоны) — Ирина продолжает руками
  - завести новый канал `writeoff_fuel` → склад «Списания» → автосоздание `СписаниеТоваров` Дт 94 Кт 41.02

## 3. Виртуальные склады (`Справочник.Склады`) — типы

Все виртуальные склады = **Оптовый склад**, тип цен = «Цена закупки».

| Имя | Код | Назначение |
|---|---|---|
| Карты | 00-000002 | принимает все cards-каналы |
| Карты Выборг | ОГ-000030 | если нужно разделение по АЗС |
| БалТоп | ОГ-000021 | возможно отдельный (но в маппинге сейчас всё на «Карты») |
| Ведомости | 00-000003 | ledger |
| ЯНДЕКС | ОГ-000016 | online |
| **Талоны** | **ОГ-000029** | voucher (создан/уже был) |
| ГБО, ГБО Автогид | 00-000008, 11 | газ |
| Пропан24 | 00-000010 | пропан |
| СЭП | ОГ-000026 | (уточнить) |
| Псков Газ | ОГ-000023 | региональная сеть |
| ЭкоГазСервис (Саперная) | ОГ-000022 | газовая АЗС |
| ЯНДЕКС | ОГ-000016 | онлайн заказы |
| Газовоз (продажа с газовоза) | ОГ-000037 | мобильная продажа |

## 4. Номенклатура для STS-маппинга

Верхняя таблица настроек: соответствие кода STS → Номенклатура (тонны/литры).

| Внешний код | Название | Номенклатура тонны | Номенклатура литры |
|---|---|---|---|
| 2 | АИ-92 | АИ-92 (т) | АИ-92 (л) |
| 3 | АИ-95 | АИ-95 (т) | АИ-95 (л) |
| 5 | Дизельное топливо | Дизельное топливо (т) | Дизельное топливо (л) |

Плотность = 1 у всех (фактическая берётся из STS поля `density`).

## 6. Дополнительные сети (system_id)

`Сети = 15` (через запятую можно несколько). Это означает что на ГИГ STS-аккаунт
обслуживает АЗС из system_id=15 (АЗС 8, 208, 209, 210) **в дополнение** к
основной 65 (АЗС 5).
