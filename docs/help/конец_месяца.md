# Закрытие месяца — пошагово

Выполняется в первой декаде следующего месяца, после окончания приёма пакетов за отчётный месяц.

## Шаг 1. Полнота приёма

- [ ] Открыть **TradeLedger → Сверка пакетов с источником**.
- [ ] Период — весь отчётный месяц.
- [ ] Сравнить количество пакетов:
  - С журналом ежедневного приёма (все ли смены пришли).
  - С центральной базой (все ли выгружены).
- [ ] Если есть недостающие — запросить переформирование.

## Шаг 2. Статусы пакетов

- [ ] Все пакеты — «ПринятоЦеликом» или «ПринятоЧастично» с понятным комментарием.
- [ ] «Отклонено» — недопустимо. Разобрать каждый.

## Шаг 3. Сверка сумм

- [ ] Итого «Сумма ЦБ» vs «Сумма БП» — расхождение должно быть ≤ 0.5% оборота.
- [ ] Если больше — разобрать пакеты с расхождением (см. [расхождение_в_сверке](расхождение_в_сверке.md)).

## Шаг 4. Сверка с поставщиками

- [ ] Стандартный отчёт БП «Расчёты с поставщиками» (60.01 / 60.02).
- [ ] Сверить с актами сверки поставщиков (за месяц/квартал).
- [ ] При расхождениях — найти оригинальные ПТУ через **«Документы пакета»**.

## Шаг 5. Сверка по 41-м счетам

- [ ] Отчёт «Оборотно-сальдовая ведомость» по 41.02 за месяц.
- [ ] Сверить с центральной базой — отчёт об остатках товара.
- [ ] Допустимое расхождение в количестве — нулевое.

## Шаг 6. Розничная выручка

- [ ] Отчёт «Карточка счёта 90.01.1» за месяц.
- [ ] Сверить с фискальными отчётами ККМ.
- [ ] При расхождениях — проверить полноту ОРП и каналов оплат.

## Шаг 7. Общепит (по новой модели B)

- [ ] Отчёт «Карточка счёта 44.01» за месяц.
- [ ] Общепит на 44.01 **не должен появляться** (если только нет других издержек обращения).
- [ ] Списания ингредиентов смотреть через «Карточка счёта 41.02» — расход + «Карточка счёта 90.02.1» — себестоимость продаж.
- [ ] См. [проводки_продажи_общепита](проводки_продажи_общепита.md).

## Шаг 8. Финальная проверка ошибок

- [ ] В форме «Загрузка из STS» нажать **«Подробный отчёт ошибок»**.
- [ ] За месяц не должно быть критичных категорий: НСИ_НеНайдена, СтавкаНДС_НеСопоставлена, СчётУчёта_НеОпределён, СуммаНеСходится.
- [ ] Если есть — разобрать (см. [реакция_на_ошибку](реакция_на_ошибку.md)).
- [ ] Допустимо: STS_ОшибкаСервера / STS_ОшибкаСети (серверные проблемы STS не зависят от настройки БП).

## Шаг 9. Архивирование

- [ ] Сделать копию основных отчётов в архив за месяц.
- [ ] Записать в журнал: «Закрытие месяца N — итог сверка X ₽ — расхождение Y ₽».
- [ ] Выгрузить дашборд формы «Загрузка из STS» в HTML (в меню «Ещё» → «Экспорт дашборда»).

## Шаг 10. Подготовка к новому месяцу

- [ ] Проверить что в каталоге OwnCloud не накопились старые файлы.
- [ ] Если есть подпапка `processed/` — переместить туда обработанные.
