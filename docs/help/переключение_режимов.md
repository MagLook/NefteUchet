# Переключение режимов

Расширение TradeLedger обрабатывает три независимых контура учёта в одной форме «Загрузка из STS (топливо)»:

- **Нефтепродукты** — приём данных по топливу через STS API (онлайн).
- **Сопутка** — приём пакетов сопутствующих товаров из центральной базы (файловый обмен).
- **Общепит** — приём пакетов общепита из центральной базы (файловый обмен).

## Как переключить

В правом-верхнем меню **«Ещё»** формы — пункт **«Режим: Нефтепродукты ▼»** с указанием текущего значения. Клик переключает на следующий контур по циклу: Нефтепродукты → Сопутка → Общепит → Нефтепродукты.

Текущий выбор сохраняется в регистре сведений **TL_Настройки** под ключом **«TL_РежимРаботы»**.

## Что меняется при переключении

| Элемент | Нефтепродукты | Сопутка | Общепит |
|---|---|---|---|
| Источник данных | STS API онлайн | Файлы tl_*.json | Файлы tl_*.json |
| Список «Тип документа» | сменные отчёты, ТТН, ПКО, СписаниеТоваров | покупка, продажа, возврат | выпуск блюд, списание |
| Дашборд KPI | Литры, выручка, остатки топлива | Документы, сумма, расхождения | Выпуск, списание сырья |
| Канал | pos.autooplata.ru/tms | OwnCloud-каталог | OwnCloud-каталог (общий) |
| Настройки | TradeLedger → Настройки расширения | TradeLedger → Настройки обмена сопутки | TradeLedger → Настройки обмена общепита |

## Какой режим выбирать

См. отдельную статью [faq_какой_режим_выбрать](faq_какой_режим_выбрать.md).

Кратко:
- Топливо проходит — Нефтепродукты.
- Поступления / продажи штучного товара — Сопутка.
- Блюда, выпечка, кулинария — Общепит.
