# Загрузка пакета

Раздел: **ElsyPlus Ledger → Сервис → ElsyPlus Ledger — Загрузка документов**.

Форма TL_Загрузка — основная точка работы бухгалтера. Через неё принимаются пакеты из центральной базы и из STS API.

## Стандартный сценарий

1. Открыть форму **ElsyPlus Ledger — Загрузка документов**.
2. Кнопкой **«Режим:»** в командной панели выбрать нужный контур: Нефтепродукты / Сопутка / Общепит. См. [переключение_режимов](переключение_режимов.md).
3. Нажать **«Опросить каталог»** (для Сопутки и Общепита). Журнал покажет список новых файлов tl_*.json и количество уже загруженных пакетов.
4. Нажать **«Обновить»** — таблицы заполнятся данными за выбранный период.
5. В левой таблице — документы, уже созданные в БП ГИГ. В правой — внешние данные из центральной базы или STS API.
6. Отметить строки во внешней таблице → нажать **«◀ Загрузить выбранные»** — документы создадутся в БП.
7. При установленном флаге **«Проводить автоматически»** в настройках обмена — документы сразу проводятся.
8. Если флаг снят — нажать **«Провести»** для отмеченных в левой таблице.

## Контроль результата

После загрузки проверить:
- В журнале — текст результата по каждой строке.
- В дашборде вверху — обновлённые KPI.
- В разделе **TL_ПросмотрСверки** — итоги по пакету (см. [сверка_пакета](сверка_пакета.md)).
- В разделе **TL_ПросмотрОшибок** — если есть записи, разобрать причины (см. [диагностика_ошибок](диагностика_ошибок.md)).

## Дополнительные действия

- **«Последние документы»** — открывает список последних созданных через TradeLedger документов с указанием типа и пакета. См. [последние_документы](последние_документы.md).
- **«Экспорт дашборда»** — сохраняет состояние дашборда в HTML-файл для отчётности.
- **«Унификация имён складов»** — приводит наименования складов АЗС к стандартному виду.
