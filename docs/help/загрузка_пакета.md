# Главная форма «Загрузка из STS»

Главная точка работы бухгалтера. Через эту форму расширение принимает:
- **Топливо** — через STS API (онлайн, реальное время).
- **Сопутку и общепит** — пакеты JSON из каталога обмена с центральной базой ЭЛСИ.АЗК.

## Где находится

**TradeLedger → Загрузка из STS (топливо)** в левой панели разделов.

## Из чего состоит форма

### Сверху: KPI-плашки

Четыре цветные плашки с показателями за период:
- Количество смен.
- Сколько в 1С (загружены).
- Сколько новых (ещё не загружены).
- Сколько ошибок.
- Выручка за период.

### Справа сверху: журнал текущей сессии

Сообщения о действиях за время работы формы. Очищается при закрытии формы.

### Посередине: фильтры

- **Тип документа для загрузки** — обычно «Все (смены + ТТН)».
- **Код станции** — конкретная АЗС или 0 для всех.
- **Дата начала / окончания** — период.

### Командная панель

Строка 1: **Тип документа** | **Код станции** | **Перезагрузить период** | **Подробный отчёт ошибок** | **Проверить остатки** | **Сбросить регистрацию**

Строка 2: **Дата начала** | **Дата окончания** | **Обновить** | **Помощь**

- **Проверить остатки** — диагностика отрицательных остатков 41.02 по складу станции (минусы после проведения, с разбором причины). Подробнее — [минусы_после_проведения](минусы_после_проведения.md).

В меню «Ещё» в правом верхнем углу:
- **Режим: Нефтепродукты ▼** — переключение контура (Нефтепродукты / Сопутка / Общепит).
- **Унификация имён складов** — выравнивание наименований складов.
- **Опросить каталог** — для сопутки и общепита.
- **Последние документы** — список созданных расширением документов.
- **Экспорт дашборда** — сохранение состояния KPI в HTML.

### Две таблицы

- **Слева — внутренние данные**: документы уже созданные в БП ГИГ. Кнопки: Выбрать все / Удалить выбранные / Провести выбранные / Зачистить аннулированные. Чекбокс **«Показать аннулированные»** выводит в список помеченные на удаление (аннулированные в ЦБ) документы — см. [расхождение_после_проведения](расхождение_после_проведения.md).
- **Справа — внешние данные**: новые смены / пакеты из источника. Кнопки: Выбрать все / Загрузить выбранные.

## Стандартный сценарий загрузки

1. Установить период (даты).
2. Опционально: выбрать конкретную АЗС в «Код станции».
3. В меню «Ещё» выбрать режим (Нефтепродукты / Сопутка / Общепит).
4. Для сопутки/общепита — «Опросить каталог».
5. **«Обновить»** — данные подтянутся.
6. Отметить строки во внешней таблице (правой).
7. **«◀ Загрузить выбранные»** — документы создадутся в БП.
8. При установленном флаге «Проводить автоматически» — документы сразу проводятся.

## Что появляется в БП после загрузки

Для **топлива** (одна смена STS):
- Отчёт о розничных продажах (выручка по топливу).
- Перемещения на виртуальные склады (Карты / ЯНДЕКС / Талоны / Ведомости).
- ПКО на сумму наличных.
- СписаниеТоваров для технических списаний (pay_type=Прочие).

Для **сопутки** (один пакет):
- ПТУ — поступление от поставщика.
- ОРП — отчёт о розничных продажах.
- КорректировкаПоступления — возвраты.

Для **общепита** (Вариант A, с 22.05.2026):
- **ОРП** — блюдо продаётся одной строкой как товар (НДС 22 %).
- **Комплектация номенклатуры** — сборка себестоимости блюда из ингредиентов (Дт 41.02 блюдо ← Кт 41.02 ингредиенты).
- **Разукомплектация** — для возвратов блюд.
- См. [общепит_что_изменилось](общепит_что_изменилось.md).

## Контроль результата

- Дашборд KPI вверху обновился.
- В журнале формы — результат по каждой строке.
- **TradeLedger → Сверка пакетов с источником** — итоги по пакетам.
- **«Подробный отчёт ошибок»** — структурированный HTML-отчёт.
