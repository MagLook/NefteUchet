# Корректировка поступления (возврат поставщику)

Если после получения товара от поставщика выяснилось что есть ошибка:
- Поставщик прислал меньше чем по накладной (часть товара отсутствует).
- Брак (часть товара испорчена и подлежит возврату).
- Цена в УПД оказалась другой чем в первоначальной накладной.

В центральной базе оформляется корректировка, и пакет с типом `return_purchase` приходит в БП ГИГ. Расширение создаёт **Документ.КорректировкаПоступления**.

## Почему именно «Корректировка», а не «Возврат поставщику»

Раньше планировалось использовать **ВозвратТоваровПоставщику** — стандартный документ БП. Но он требует учёта по партиям FIFO (нужно знать из какой именно партии возвращается товар). Это усложняет приём — приходится отдельно вычислять партию для каждой возвращаемой позиции.

**КорректировкаПоступления** работает без явной привязки к партии — просто уменьшает сумму и количество оригинального ПТУ. Поэтому используется она.

## Какие проводки

КорректировкаПоступления формирует **обратные проводки** относительно оригинального поступления (со знаком минус):

| Дт | Кт | Содержание |
|---|---|---|
| 41.02 | 60.01 | Уменьшение поступления товара (минус) |
| 19.03 | 60.01 | Уменьшение НДС (минус) |

> В КорректировкеПоступления расширение включает флаг **«Корректировать БУ и НУ» = Да** — сторно-проводки формируются и в бухгалтерском, и в налоговом учёте (не только по НДС).

Если оригинальный документ оплачен и был автозачёт (60.02 → 60.01) — корректировка **не трогает** 60.02. Остаётся для ручного анализа.

## Из чего собирается документ

- **Шапка**: ссылка на исходное Поступление, организация, договор, склад.
- **ТЧ Товары**: те же позиции что в оригинале, но с уточнёнными значениями (количество меньше или цена другая).

## Где посмотреть документ

1. **TradeLedger → Сверка пакетов с источником**.
2. Найти пакет с корректировкой.
3. «Документы пакета» → двойной клик по «КорректировкаПоступления».

Или через журнал:
1. **Покупки → Корректировки поступлений**.

## Что проверить

1. **Ссылка на оригинальное Поступление** — открыть документ, проверить что ссылка есть и ведёт на правильное ПТУ.
2. **Количество и сумма** — должны соответствовать новой накладной/УПД.
3. **Проводки** — Дт/Кт показывает обратные проводки на сумму корректировки.

## Типовые проблемы

### Не найдено оригинальное Поступление

Пакет ссылается на ПТУ которого нет в БП. Возможно ПТУ не было загружено, или его удалили.

**Что делать:**
1. Проверить регистр «TL_СоответствиеИсточников» — есть ли запись для оригинального UUID.
2. Если есть — найти документ по ссылке.
3. Если нет — загрузить недостающий пакет с оригинальным ПТУ (возможно надо «Перезагрузить период» за более старый период).

### Полный возврат поставщику

Если возвращается **вся** партия (не корректировка, а полный возврат) — рекомендуется оформлять отдельным документом **ВозвратТоваровПоставщику** вручную. Корректировка для частичного возврата.
