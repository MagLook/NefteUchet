# FAQ: Неизвестный контрагент в пакете

В пакете указан контрагент с UUID, которого нет в карточках контрагентов БП ГИГ. Документ не создан, в TL_ОшибкиЗагрузки запись с категорией **НСИ_НеНайдена** и Тип = Контрагент.

## Стандартные действия

### Вариант 1. Контрагент уже есть в БП с другим UUID

Возможно карточка контрагента в БП ГИГ заведена давно и не привязана к центральной базе.

1. Открыть **TradeLedger → Журнал ошибок загрузки** → найти запись → посмотреть ИсточникUUID и ЗначениеИсточника (там обычно ИНН и наименование из центральной базы).
2. Покупки → Контрагенты → поиск по ИНН.
3. Если контрагент найден — внести соответствие через регистр TL_СоответствиеИсточников:
   - Тип = «Контрагент»
   - ИсточникUUID = из ошибки
   - Ссылка = найденный контрагент
4. В форме «Загрузка из STS» нажать «Перезагрузить период» → «Да» (Дозагрузить).

### Вариант 2. Контрагент новый

1. Создать карточку контрагента в БП ГИГ (Покупки → Контрагенты → Создать).
2. Заполнить ИНН, наименование, договор «С поставщиком» с видом расчётов 60.01 / 60.02.
3. После создания запустить «Перезагрузить период» → «Дозагрузить» — автомаппинг по ИНН сработает.

### Вариант 3. В пакете ошибка

Возможно в центральной базе оператор указал неверного контрагента (или удалил карточку).

1. Согласовать с центральной базой — какой контрагент должен быть.
2. Поправить документ в центральной базе.
3. Переформировать пакет.
4. Загрузить заново через «Перезагрузить период» → «Дозагрузить».

## Особый случай: ГАЗИНВЕСТГРУПП как контрагент

Внутри сети при передаче товара между организациями (например в День X с НЛ на ГИГ) одна организация становится контрагентом другой.

- В БП ГИГ организация ГАЗИНВЕСТГРУПП должна одновременно быть в:
  - Справочник Организации (как основная организация учёта)
  - Справочник Контрагенты — отдельная карточка с тем же ИНН (для отражения операций когда ГИГ выступает как поставщик / покупатель относительно другой организации сети)

- Аналогично НОРД-ЛАЙН должен быть и в Организациях (если оригинальная база), и в Контрагентах (если используется как контрагент в документах ГИГ).

При первоначальной настройке проверить наличие обеих карточек.
