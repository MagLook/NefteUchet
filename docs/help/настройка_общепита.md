# Настройка обмена общепита

Раздел: **TradeLedger → Настройки обмена общепита (ЦБ → БП)**.

Форма задаёт параметры приёма пакетов общепита (блюда, ингредиенты) из центральной базы.

## Как работает учёт общепита сейчас (Вариант A)

- Блюдо продаётся ОДНОЙ строкой в ОРП как товар (НДС 22 %).
- Себестоимость собирается отдельным документом **«Комплектация номенклатуры»** из
  ингредиентов по рецепту (Дт 41.02 блюдо ← Кт 41.02 ингредиенты).
- Возврат блюда — документом **«Разукомплектация»**.
- Документы ОПЗС (отчёт производства) **не создаются**.

Подробнее — [как_продаётся_блюдо](как_продаётся_блюдо.md),
[проводки_продажи_общепита](проводки_продажи_общепита.md).

## Первичная настройка

1. **TradeLedger → Настройки обмена общепита (ЦБ → БП)**.
2. Кнопка **«Заполнить по умолчанию»**:
   - Организация — ГАЗИНВЕСТГРУПП.
   - Подразделение — с «208» в наименовании.
   - Счёт готовой продукции / сырья — **41.02** (товары в рознице).
   - Статья затрат — «Списание материалов».
   - Номенклатурная группа — «Общепит» / «Производство» (если существует).
3. Проверить подобранные значения (особенно Номенклатурную группу).
4. Заполнить **«Каталог OwnCloud»** (общий с Сопуткой).
5. **«Сохранить настройки»**.

## Ключевые настройки (регистр TL_Настройки)

| Ключ | Дефолт | Смысл |
|---|---|---|
| `Общепит_МодельУчёта` | `B` | Базовая модель учёта (B = списание по ТТК, ГИГ) |
| `Общепит_КомплектацияБлюд` | `1` | `1` = Вариант A (блюдо одной строкой + Комплектация); `0` = legacy |
| `Розница_ФорсНДС22Аварийный` | `0` | Аварийный режим: `1` = подменять построчный НДС на 22 % |
| `Защита_НеПерезаписыватьПроведённые` | `1` | `1` = не перезаписывать проведённый бухгалтером документ при повторной загрузке (расхождение помечается ⚠) |

> Значение `Общепит_МодельУчёта=B` **менять не нужно**: «модель B» здесь означает учёт по ТТК (по рецептам). В текущей реализации она воплощена в подварианте **Вариант A** — блюдо продаётся одной строкой в ОРП, а себестоимость собирается отдельным документом «Комплектация номенклатуры».

Про защиту проведённых и знак ⚠ —
[расхождение_после_проведения](расхождение_после_проведения.md).

## Счета учёта

- **41.02** — «Товары в розничной торговле». На нём лежат и ингредиенты (сырьё), и
  собранные блюда; Комплектация переносит себестоимость сырья на блюдо в пределах 41.02.
- При продаже себестоимость блюда уходит с 41.02 на 90.02.1.

## Когда повторно настраивать

- При смене каталога обмена, основной организации, подразделения или счетов учёта.
