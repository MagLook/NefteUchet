# НефтеУчёт — расширение для 1С:Бухгалтерия 3.0

Расширение конфигурации (.cfe) для автоматизации учёта нефтепродуктов на сетях АЗС.

## Что делает

- Подключается к облаку (API STS / ClearLedger) и получает готовые данные
- Загружает **сменные отчёты** и **поступления топлива** (ТТН)
- Создаёт документы 1С по команде бухгалтера:
  - Поступление товаров (41.01, тонны)
  - Комплектация (тонны → литры по плотности из ТТН)
  - Перемещение на склады АЗС и виртуальные склады (Карты, Талоны, Ведомости)
  - Отчёт о розничных продажах (наличные + эквайринг)

## Совместимость

- 1С:Бухгалтерия предприятия 3.0 (ПРОФ, Базовая)
- Платформа 8.3.20+
- Файловая и клиент-серверная базы

## Сборка

```powershell

```

## Установка

1. Открыть 1С в режиме Конфигуратора
2. Конфигурация → Расширения конфигурации → Добавить из файла
3. Выбрать `build/НефтеУчёт.cfe`
4. Обновить конфигурацию базы данных

## API

Расширение получает данные из STS API (`pos.autooplata.ru/tms`):
- `POST /v1/login` → JWT-токен
- `GET /v1/report/shift_report` → сменный отчёт
- `GET /v1/report/receipts` → поступления (ТТН)
