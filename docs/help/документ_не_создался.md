# Документ не создался при загрузке

Бухгалтер видит: пакет загружен, но в БП документ не появился. Или появился, но не все строки.

## Где искать причину

1. В форме **«Загрузка из STS»** нажать **«Подробный отчёт ошибок»**.
2. Категория ошибки покажет суть проблемы.
3. Альтернативно — **TradeLedger → Сверка пакетов с источником** → найти пакет → «Показать ошибки пакета».

## Типовые причины

### Маппинг оплат не найден

В смене STS встретился новый вид оплаты (например, новый банк-эквайринг).

**Решение:** добавить запись в **TradeLedger → Маппинг видов оплат STS**. Образец имени — из колонки «Значение» в отчёте.

После добавления — **«Перезагрузить период»** → **«Да» (Дозагрузить)**.

### Контрагент не найден

Поставщик отсутствует в БП ГИГ.

**Решение:** создать карточку через **Покупки → Контрагенты → Создать**. Или см. [неизвестный_контрагент](неизвестный_контрагент.md).

### Номенклатура не найдена

Карточка товара отсутствует в БП ГИГ.

**Решение:** создать через **Справочники → Номенклатура → Создать**.

### Склад / Организация / Подразделение не найдены

Указанный элемент отсутствует или неправильно настроен.

**Решение:** создать в справочнике или поправить настройки обмена ([настройка_сопутки](настройка_сопутки.md) / [настройка_общепита](настройка_общепита.md)).

### Обязательное поле пусто

Источник не передал важное значение.

**Решение:** сообщить в центральную базу, оператор переформирует пакет.

### Ставка НДС не сопоставлена

Передана неизвестная ставка.

**Решение:** сообщить обслуживающей организации.

### Ошибка проведения

Документ создан, но не провёлся (остатки, реквизиты).

**Решение:** открыть документ из колонки «Пакет» в журнале сверки, нажать «Провести» в БП, прочитать ошибку, устранить.

### STS-ошибки

Серверные/сетевые проблемы — не настройка БП. Подождать, см. [категории_ошибок](категории_ошибок.md).

### Блюдо не списалось

Особый случай для общепита по Варианту A. См. [блюдо_не_списалось](блюдо_не_списалось.md).

## После исправления

Если правка в БП ГИГ:
- В форме «Загрузка из STS» → **«Перезагрузить период»** → **«Да» (Дозагрузить)**.
- Будут созданы только недостающие документы. Дубли невозможны.

Если правка в центральной базе (переформирован пакет):
- Дождаться переформирования файла (несколько минут).
- В меню «Ещё» нажать **«Опросить каталог»** — увидеть обновлённый файл.
- **«Перезагрузить период»** → **«Да»**.

## Если ничего не помогает

- Скриншот подробного отчёта ошибок.
- Скриншот любых системных сообщений.
- Сообщение в обслуживающую организацию с указанием:
  - Какой пакет (UUID).
  - Какая категория ошибки.
  - Какие действия делали.
