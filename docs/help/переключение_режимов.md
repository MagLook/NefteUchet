# Три режима работы — топливо / сопутка / общепит

Расширение TradeLedger работает с тремя независимыми контурами учёта в одной форме «Загрузка из STS». Бухгалтер переключает контур одной кнопкой.

## Три режима

| Режим | Что обрабатывает | Источник данных |
|---|---|---|
| **Нефтепродукты** | Топливо: смены, ТТН, ПКО, технические списания | STS API онлайн (`pos.autooplata.ru/tms`) |
| **Сопутка** | Сопутствующие товары: чипсы, напитки, табак, журналы | Пакеты JSON в каталоге OwnCloud |
| **Общепит** | Блюда: кофе, выпечка, кулинария | Пакеты JSON в том же каталоге |

## Как переключить

В форме «Загрузка из STS» в правом верхнем углу — меню **«Ещё»**. Внутри пункт **«Режим: Нефтепродукты ▼»** (или Сопутка / Общепит — в зависимости от текущего значения).

Клик переключает на следующий контур по циклу: Нефтепродукты → Сопутка → Общепит → Нефтепродукты.

Выбор сохраняется до следующего изменения.

## Что меняется при переключении

| Элемент | Нефтепродукты | Сопутка | Общепит |
|---|---|---|---|
| Источник данных | STS API онлайн | Файлы tl_*.json | Файлы tl_*.json |
| Список «Тип документа» | смены, ТТН, ПКО, списания | покупка, продажа, возврат | выпуск, списание (модель A) / только синхронизация ТТК (модель B) |
| Дашборд KPI | литры, выручка, остатки топлива | документы, сумма, расхождения | выпуск, списание ингредиентов |
| Где настройки | TradeLedger → Настройки расширения | TradeLedger → Настройки обмена сопутки | TradeLedger → Настройки обмена общепита |

## Какой режим выбирать

### Нефтепродукты

Если работаете с топливом: загрузка смен через STS, проверка остатков, ТТН поступлений топлива, технические списания (Прочие).

### Сопутка

Если приходит штучный товар: партия чипсов, новая поставка автохимии, продажи кассового аппарата по штучке.

### Общепит

Если работаете с блюдами: новые рецепты (ТТК), синхронизация спецификаций. **В модели B продажи блюд попадают в ОРП через режим Сопутка** (см. [общепит_что_изменилось](общепит_что_изменилось.md)).

## Кросс-режимные операции

Некоторые сценарии затрагивают несколько режимов:
- Перевод сырья из сопутки в общепит — оформляется через ТребованиеНакладная в центральной базе.
- Продажа блюда (общепит) — в модели B попадает в ОРП Сопутки с раскладкой на ингредиенты.

В большинстве случаев переключение режима — это просто **фильтр** для удобства просмотра. При загрузке расширение само определит тип пакета и обработает корректно.
