# FAQ: Блюдо продано, а себестоимость не собралась

Бухгалтер видит ОРП с продажей Эспрессо ×3 = 240 ₽ (одна строка «Эспрессо» — это
**норма**), но по блюду **нет парной «Комплектации номенклатуры»**, и на счёте 90.02.1
себестоимость нулевая или блюдо ушло в минус на 41.02.

> Важно: блюдо ОДНОЙ строкой в ОРП — это правильно (Вариант A). Проблема не в этом,
> а в том, что **не создалась Комплектация**, которая собирает себестоимость блюда из
> ингредиентов. Без неё продажа есть, а собранной себестоимости — нет.

## Что это значит

Расширение не нашло **рецепт** (Спецификацию номенклатуры) для Эспрессо, поэтому не
смогло создать документ «Комплектация номенклатуры». Блюдо продалось как товар, но его
себестоимость не собрана.

## Где увидеть подтверждение

1. Откройте форму **TradeLedger → Загрузка из STS**.
2. Нажмите **«Подробный отчёт ошибок»**.
3. Найдите категорию **НСИ_НеНайдена** (бирюзовый цвет).
4. Ищите запись вида:
   ```
   Блюдо «Эспрессо 60мл» — нет спецификации (ТТК не синхронизирован из ЦБ).
   Комплектация не создана, себестоимость не собрана.
   ```
5. Косвенный признак — в карточке смены (двойной клик по строке витрины) у блюда нет
   отметки собранной себестоимости, а в журнале «Комплектация номенклатуры» за смену
   документа по блюду нет.

## Возможные причины

### 1. Рецепт ещё не пришёл из центральной базы

Самая частая причина — технолог в ЦБ только что создал блюдо/рецепт или забыл сохранить
его с пометкой «передавать в БП».

**Действие:**
- Сообщите технологу ЦБ, что для блюда «N» нет рецепта в БП ГИГ.
- Технолог пересохранит ТТК → через несколько минут пакет с рецептом придёт в БП.
- После прихода — «Загрузка из STS» → **«Перезагрузить период»** → **«Да» (Дозагрузить)**
  для нужного периода. Расширение создаст недостающую Комплектацию.
  ⚠ Если ОРП смены уже проведён — см. раздел «Если ОРП уже проведён» ниже.

### 2. Рецепт есть, но помечен на удаление

Технолог пометил старый рецепт на удаление, новый ещё не синхронизировался.

**Действие:** «Все функции → Справочники → Спецификации номенклатуры», найти блюдо;
если есть только помеченные — дождаться синхронизации нового или попросить ускорить.

### 3. Блюдо не отмечено как блюдо в центральной базе

Если в ЦБ не установлен признак «это блюдо» — строка придёт как обычный товар, и
Комплектация не создаётся даже при наличии рецепта.

**Действие:** сообщить технологу: «Блюдо N приходит без признака „ЭтоБлюдо“».

### 4. ОРП создан по старой схеме (до перехода на Вариант A)

Исторические документы могли создаваться по прежней модели. Для них текущая логика не
применяется — это норма для старых периодов, переделывать не нужно.

## Чем грозит несобранная себестоимость

- **Есть остаток блюда на 41.02** — списание пройдёт по имеющемуся остатку; прибыль
  может быть искажена (себестоимость не по ингредиентам).
- **Нет остатка блюда** — отрицательный остаток на 41.02 по блюду. Закрытие месяца не
  сорвётся, но в «ОСВ по 41.02» будет отрицательное сальдо — придётся объяснять.

## Как избежать

- При запуске общепита на новой АЗС — сначала синхронизировать все ТТК, потом включать
  продажи блюд.
- В первые дни — ежедневно проверять «Подробный отчёт ошибок» на НСИ_НеНайдена.
- При изменении рецепта в ЦБ — технологу убеждаться, что обновлённая версия пришла в БП.

## Если ОРП уже проведён

Если ОРП смены уже проведён бухгалтером, повторная загрузка его **не перезапишет**
(защита проведённых), а пометит смену знаком **⚠** в витрине. Чтобы принять
исправление и досоздать Комплектацию:

1. Снимите проведение с ОРП смены.
2. «Перезагрузить период» → «Да (Дозагрузить)».
3. Проведите смену через витрину (Комплектация → ОРП).

Подробнее — [расхождение_после_проведения](расхождение_после_проведения.md).

## Что делать с уже сформированным неправильно

1. **До закрытия месяца:** снять проведение / пометить на удаление неправильные
   документы, «Сбросить регистрацию» для периода и АЗС (подменю «Ещё»), дождаться ТТК,
   «Перезагрузить период» → «Да (Дозагрузить)», провести смену.
2. **После закрытия месяца:** ретроспективно не переделывается; значимое расхождение —
   корректировкой в текущем месяце.
