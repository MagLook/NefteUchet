# Справка TradeLedger — расширение БП ГИГ

Расширение TradeLedger в БП «Бухгалтерия предприятия 3.0» (ГАЗИНВЕСТГРУПП) принимает данные из центральной базы ЭЛСИ.АЗК и из STS API, создаёт документы и формирует проводки.

Раздел: **ElsyPlus Ledger** в левом меню Предприятия.
