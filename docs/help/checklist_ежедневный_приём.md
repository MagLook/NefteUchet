# Чек-лист: Ежедневный приём пакетов

Выполняется один или несколько раз в день в зависимости от частоты поступления данных из STS API (топливо) и центральной базы (сопутка, общепит).

## Утренний приём (вчерашние смены)

### Шаг 1. Топливо (STS API)

- [ ] Открыть **TradeLedger → Загрузка из STS (топливо)**.
- [ ] В меню «Ещё» проверить что режим = «Нефтепродукты».
- [ ] Установить «Дата начала» = вчера, «Дата окончания» = вчера (или текущий период).
- [ ] Нажать «Обновить» — данные подтянутся через STS API за указанный период.
- [ ] Внешняя таблица заполнится сменами. Если ожидаемых смен нет — проверить лог на ошибки авторизации или сети STS.
- [ ] Отметить новые смены (кнопка «Выбрать все») → «◀ Загрузить выбранные».
- [ ] Дождаться завершения, прочитать журнал.

### Шаг 2. Сопутка

- [ ] В меню «Ещё» переключить режим на «Сопутка».
- [ ] Нажать «Опросить каталог» — журнал покажет сколько новых файлов и сколько уже загружено.
- [ ] «Обновить» → внешняя таблица заполнится.
- [ ] Отметить все строки → «◀ Загрузить выбранные».
- [ ] Дождаться завершения, прочитать журнал.

### Шаг 3. Общепит

- [ ] В меню «Ещё» переключить режим на «Общепит».
- [ ] Повторить шаги 2 — опрос каталога и загрузка.

### Шаг 4. Контроль сверки

- [ ] Открыть **TradeLedger → Сверка пакетов с источником**.
- [ ] Период по умолчанию — последние 7 дней. Можно сузить до вчера.
- [ ] Проверить статусы:
  - Зелёные («ПринятоЦеликом») — действий не требуется.
  - Жёлтые («ПринятоЧастично») — открыть «Показать ошибки пакета», см. [checklist_реакция_на_ошибку](checklist_реакция_на_ошибку.md).
  - Красные («Отклонено») — то же, срочнее.
- [ ] Записать расхождения если они есть.

### Шаг 5. Подробный отчёт ошибок

- [ ] В форме «Загрузка из STS» нажать **«Подробный отчёт ошибок»**.
- [ ] Открывшийся отчёт показывает все ошибки за сегодня сгруппированные по категориям.
- [ ] Если ошибок нет — «✓ Ошибок нет», закрыть окно.
- [ ] Если есть — для каждой категории прочитать блок «Что делать», при необходимости открыть «📖 Подробнее».

### Шаг 6. Подтверждение

- [ ] Все пакеты обработаны — сообщить центральной базе (если требуется по регламенту).
- [ ] Записать в свой журнал: «Приём за дату N — N пакетов, M ошибок, расхождение X ₽».

## Дневной приём (текущие смены)

Аналогично утреннему, но обычно меньший объём. Период приёма зависит от регламента центральной базы (часто 12:00, 18:00, 24:00).

## Когда нужно подключить администратора расширения

- При появлении ошибок с категорией **STS_ОшибкаСервера** (HTTP 5xx) если повторяются более 30 минут.
- При расхождениях > 100 ₽ за один пакет.
- При систематических ошибках по одному поставщику.
- При недоступности каталога OwnCloud (журнал сообщает об ошибке проверки).
- При появлении категории **МаппингОплат_НеНайден** с новым именем — нужно завести запись в маппинге.
