# FAQ: Какой режим выбрать в TL_Загрузка

В форме TL_Загрузка кнопка **«Режим:»** переключает контур учёта. Текущий выбор определяет что показывает дашборд и какие типы документов доступны.

## Когда выбирать какой режим

### Нефтепродукты
- Приём данных о продажах топлива через STS API.
- Контроль остатков топлива по резервуарам.
- Сменные отчёты по ТРК (топливораздаточным колонкам).
- Документы: сменные отчёты, ТТН, ПКО.

Источник данных: онлайн через `pos.autooplata.ru/tms`. Файлы tl_*.json не нужны.

### Сопутка
- Приём пакетов сопутствующих товаров (всё что не топливо и не общепит): автохимия, фастфуд в упаковке, журналы, аксессуары.
- Поступления, продажи, возвраты, перемещения, инвентаризации.
- Документы: ПТУ, ОРП, КорректировкаПоступления.

Источник данных: файлы tl_*.json в каталоге OwnCloud, формируются центральной базой.

### Общепит
- Приём пакетов общепита: выпуск блюд (выпечка, кулинария), списание сырья по ТТК.
- Документы: ОПЗС.

Источник данных: файлы tl_*.json в том же каталоге OwnCloud.

## Что если режим определить трудно

- Если в пакете указан явный kind (`purchase`, `retail_sale_sidegoods`, `production_release`, `return_purchase`) — он сам определяет режим, в котором будет показан.
- Дашборд при загрузке отфильтрует только относящееся к текущему режиму.
- При сомнении — переключить режим и посмотреть содержит ли пакет данные.

## Кросс-режимные операции

Некоторые сценарии затрагивают несколько режимов:
- Перевод сырья из сопутки в общепит — оформляется через ТребованиеНакладная в центральной базе.
- Продажа выпущенного блюда — отражается в Сопутке (ОРП) как продажа товара 41.02 (поскольку выпущенное блюдо тоже на счёте 41.02).
