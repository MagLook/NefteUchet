# FAQ: Расхождение в сверке пакета

В форме **TradeLedger → Сверка пакетов с источником** колонка **Расхождение** показывает разницу: СуммаБП − СуммаЦБ.

Если значение больше 0.01 ₽ по модулю — колонка подсвечена красным.

## Возможные причины

### 1. Округление при пересчёте

- Цена с учётом НДС в центральной базе и цена без НДС с раздельным НДС в БП могут давать разницу в копейках при округлении.
- Допустимое значение: до нескольких рублей на пакет с сотнями строк.
- Действие: записать в комментарий «округление НДС», далее не пересматривать.

### 2. Пропущенная строка из-за ошибки

- В пакете была строка, которую не удалось обработать (отсутствует справочник, неизвестный pay_type, ошибка проведения).
- Категория ошибки появится в **«Подробный отчёт ошибок»** (кнопка в форме «Загрузка из STS»).
- Действие: устранить причину, в форме «Загрузка из STS» нажать **«Перезагрузить период»** → **«Да» (Дозагрузить)**.

### 3. Двойной учёт

- Пакет загружен дважды по разным каналам (например через автомат и вручную).
- Признак: документ в БП есть, но в TL_СоответствиеИсточников отсутствует ИдентификаторПоследнегоПакета совпадающий с пакетом.
- Действие: проверить регистр TL_СоответствиеИсточников по ИсточникUUID документа, удалить лишний документ вручную.

### 4. Изменение в центральной базе после выгрузки

- Документ изменён в центральной базе уже после формирования пакета — расхождение возникает естественно.
- Действие: переформировать пакет в центральной базе и нажать **«Перезагрузить период»** → **«Да» (Дозагрузить)**.

### 5. Разная учётная политика по НДС

- Центральная база работает с НДС 22%, в пакете передаётся 22%, но в БП ГИГ карточка номенклатуры с НДС 20% или Без НДС.
- Действие: согласовать ставки. Поправить карточку номенклатуры в БП или передавать с правильной ставкой.

## Что делать при первом обнаружении

1. Открыть пакет в сверке → проверить колонку Ошибок — если есть, начать с них.
2. Открыть «Документы пакета» → посмотреть документы → сравнить с центральной базой.
3. Если документ создан, но сумма отличается — открыть документ, посмотреть проводки через Дт/Кт.
4. Если расхождение копеечное — записать в комментарий причину и оставить.
5. Если расхождение значимое — устранить корневую причину в центральной базе, перезагрузить через «Перезагрузить период» → «Дозагрузить».

## Когда срочно эскалировать

- Расхождение > 100 ₽ на одном пакете.
- Расхождение в нескольких пакетах подряд по одному поставщику.
- Расхождение по налоговым счетам (68.02, 19.03).

В этих случаях — сообщить обслуживающей организации и приостановить автоматическое проведение до выяснения.
