# Справка TradeLedger — расширение БП ГИГ

Расширение **TradeLedger** в БП «Бухгалтерия предприятия 3.0» (ГАЗИНВЕСТГРУПП) принимает данные из STS API (топливо, реальное время) и из центральной базы ЭЛСИ.АЗК (сопутка, общепит — пакеты JSON через каталог), создаёт документы и формирует проводки.

Раздел: **TradeLedger** в левой панели разделов 1С:Предприятия.
