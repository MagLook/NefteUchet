# Сборка форм TL_НастройкаОбменаСопутка и TL_НастройкаОбменаОбщепит

Полный путь к документу: `D:\Users\magsp\ELSYPLUS\NefteUchet\docs\TL_НастройкаОбмена_сборка_форм.md`

Обе обработки уже описаны в xml-манифестах и имеют готовые программные модули. Чтобы они открывались в режиме Предприятия, требуется собрать в Конфигураторе файл `Form.bin` для каждой (модуль и список реквизитов в репозитории есть, Form.bin перепаковывается только средствами 1С).

## Подключение

1. Открыть Конфигуратор расширения `TradeLedger` в БП ГИГ:
   - База: GIG Base2 (`D:\Bases\GIG_Base2\`)
   - Пользователь: `Гайворонская Татьяна`, пароль `12345`
2. Меню **Конфигурация → Расширения конфигурации → TradeLedger → Открыть конфигурацию расширения**.

## Загрузка манифестов обработок из репозитория

Если в дереве расширения обработок `TL_НастройкаОбменаСопутка` и `TL_НастройкаОбменаОбщепит` ещё нет — загрузить их из исходников:

1. **Конфигурация → Загрузить конфигурацию из файлов**.
2. Каталог исходников: `D:\Users\magsp\ELSYPLUS\NefteUchet\xml-v4\`.
3. Режим — частичная загрузка, выбрать:
   - `DataProcessors/TL_НастройкаОбменаСопутка.xml`
   - `DataProcessors/TL_НастройкаОбменаОбщепит.xml`
4. Подтвердить.

После загрузки в ветке **Обработки** появятся обе обработки без формы.

## TL_НастройкаОбменаСопутка

### Шаг 1. Создать форму

1. В дереве расширения: **Обработки → TL_НастройкаОбменаСопутка → Формы → Добавить**.
2. Конструктор формы:
   - Имя: `Форма`
   - Назначение: `Форма обработки`
   - Тип формы: **Обычная** (не управляемая)
   - Назначить основной — ДА
3. **Готово**.

### Шаг 2. Добавить реквизиты формы

Через **Свойства формы → Реквизиты → Добавить реквизит**:

| Имя | Тип | Длина | Примечание |
|---|---|---|---|
| `КаталогOwnCloud` | Строка | 255 | Путь к каталогу обмена |
| `КонтрагентИсточник` | СправочникСсылка.Контрагенты | — | НЛ-контрагент (зеркало) |
| `Организация` | СправочникСсылка.Организации | — | ГИГ |
| `СкладПоУмолчанию` | СправочникСсылка.Склады | — | АЗС Выборг (208) |
| `Подразделение` | СправочникСсылка.ПодразделенияОрганизаций | — | по умолчанию |
| `СтатьяДДСНаличные` | СправочникСсылка.СтатьиДвиженияДенежныхСредств | — | для ПКО |
| `ВидОплатыБезнал` | СправочникСсылка.ВидыОплатОрганизаций | — | для эквайринга (элемент «Платежная карта») |
| `ПроводитьАвтоматически` | Булево | — | по умолчанию `Истина` |
| `ТекстЛога` | Строка | — | многострочная, неогранич. |

### Шаг 3. Разместить элементы формы

Простая раскладка одной колонкой:

```
[Группа «Транспорт»]
  Поле «КаталогOwnCloud»                       [Кнопка «Проверить каталог»]

[Группа «Источник в ЦБ»]
  Поле «КонтрагентИсточник»

[Группа «Получатель в БП ГИГ»]
  Поле «Организация»
  Поле «СкладПоУмолчанию»
  Поле «Подразделение»

[Группа «Финансовые настройки»]
  Поле «СтатьяДДСНаличные»
  Поле «ВидОплатыБезнал»

[Группа «Поведение»]
  Флаг «ПроводитьАвтоматически»

[Командная панель формы]
  Кнопка «Заполнить по умолчанию»   → команда ЗаполнитьПоУмолчанию
  Кнопка «Загрузить настройки»       → команда ЗагрузитьНастройки
  Кнопка «Сохранить настройки»       → команда СохранитьНастройки

[Группа «Журнал»]
  Поле «ТекстЛога» (многострочное, высота 8 строк, ТолькоПросмотр=Истина)
```

### Шаг 4. Команды формы

Через **Свойства формы → Команды → Добавить команду**:

| Имя команды | Действие (процедура модуля формы) |
|---|---|
| `ЗагрузитьНастройки` | `ЗагрузитьНастройки` |
| `СохранитьНастройки` | `СохранитьНастройки` |
| `ЗаполнитьПоУмолчанию` | `ЗаполнитьПоУмолчанию` |
| `ПроверитьКаталог` | `ПроверитьКаталог` |

Все процедуры уже описаны в `src/DataProcessors/TL_НастройкаОбменаСопутка/Forms/Форма/Module.bsl` с пометкой `Экспорт`.

### Шаг 5. Подгрузить модуль формы

Содержимое модуля уже лежит в `D:\Users\magsp\ELSYPLUS\NefteUchet\src\DataProcessors\TL_НастройкаОбменаСопутка\Forms\Форма\Module.bsl`. Открыть модуль формы в Конфигураторе и заменить весь текст содержимым этого файла. ### Шаг 6. Сохранение и применение

1. **Файл → Сохранить** (или Ctrl+S).
2. **Конфигурация → Обновить конфигурацию базы данных** (F7).
3. Принять реструктуризацию.

## Проверка

После обновления базы:

1. В режиме Предприятия открыть **Все функции → Обработки → TradeLedger — Настройка обмена: Сопутка**.
2. Нажать **Заполнить по умолчанию** → значения подставлены (ГИГ, склад 208, статья «Розничная выручка»).
3. Нажать **Сохранить настройки** → в журнале появится `Настройки сохранены`.
4. Открыть **Все функции → Регистры сведений → TL_Настройки** и убедиться, что появились записи с префиксом `Сопутка_`.
5. То же повторить для **Настройка обмена: Общепит** — должны появиться записи с префиксом `Общепит_`.

После настройки обеих обработок в основной форме **TL_Загрузка** при переключении режима «Сопутка»/«Общепит» дашборд будет читать соответствующие настройки из `TL_Настройки`.
