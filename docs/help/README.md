# Справка TradeLedger — для бухгалтера ГИГ

Это встроенная справка для бухгалтера. Никакого программирования — только бухгалтерские действия, конкретные кнопки и понятные объяснения.

Расширение **TradeLedger** в БП «Бухгалтерия предприятия 3.0» (ГАЗИНВЕСТГРУПП) автоматически создаёт документы и проводки по данным с АЗС. Не нужно вручную заводить смены, продажи, поступления топлива и блюд — расширение делает это самостоятельно. Бухгалтеру остаётся проверять и подтверждать.

Раздел: **TradeLedger** в левой панели разделов 1С:Предприятия.
