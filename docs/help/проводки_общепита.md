# Проводки общепита (выпуск + списание сырья)

kind пакета: **`production_release`**.

Создаётся документ **ОтчётПроизводстваЗаСмену** (ОПЗС) с видом операции **ОтчётПроизводстваЗаСмену**.

## Проводки

Для табличной части «Продукция» — на каждое блюдо (выпущенное за смену):

| Дебет | Кредит | Содержание |
|---|---|---|
| 41.02 | 44.01 | Оприходование готовой продукции (блюда) |

Для табличной части «Материалы» — на каждый ингредиент (списанное сырьё):

| Дебет | Кредит | Содержание |
|---|---|---|
| 44.01 | 41.02 | Списание сырья на затраты выпуска |

Итог: количество выпущенных блюд и потраченных ингредиентов через счёт 44.01.

## Структура документа

- Шапка: дата смены, организация, подразделение, номенклатурная группа, счёт затрат, счёт ГП.
- Табличная часть «Продукция» — выпуск (например 11 позиций блюд).
- Табличная часть «Материалы» — списание ингредиентов (например 51 позиция сырья).

Связь продукция ↔ материалы задаётся в центральной базе ЭЛСИ.АЗК через ТТК (технико-технологические карты) и регистрируется при оформлении выпуска. В БП ГИГ передаётся уже готовая пара.

## Контроль

- Сумма по «Продукции» (по продажной цене) обычно больше суммы по «Материалам» (по себестоимости) — это нормально, это маржа общепита.
- Если суммы равны или продукция меньше — возможно ошибка в ТТК или в передаче. Проверить документ ВыпускПродукции в центральной базе.
- Расхождение фиксируется в TL_СверкаПакета только если сумма пакета не совпадает с суммой созданного документа (округления, потерянные строки).

## Типовые проблемы

- **Не найдена номенклатура продукции** — карточка блюда в БП ГИГ отсутствует. Завести вручную или через автомаппинг по UUID.
- **Не найдена номенклатура материалов** — аналогично для ингредиентов.
- **Счёт 44.01 не определён** — настроить **TradeLedger → Настройки обмена общепита** → «Счёт затрат».
- **Номенклатурная группа пустая** — настроить там же.
