# Настройка обмена: Общепит

Раздел: **ElsyPlus Ledger → Сервис → TradeLedger — Настройка обмена: Общепит**.

Форма задаёт параметры приёма пакетов общепита (выпуск блюд, списание сырья) из центральной базы.

## Чек-лист первичной настройки

1. Открыть форму **TradeLedger — Настройка обмена: Общепит**.
2. Нажать **«Заполнить по умолчанию»** — подбираются:
   - Организация — ГАЗИНВЕСТГРУПП
   - Подразделение — с «208» в наименовании
   - Счёт затрат — **44.01** (издержки общепита)
   - Счёт готовой продукции / сырья — **41.02** (товары в рознице)
   - Статья затрат — «Списание материалов» (если такая существует в справочнике)
   - Номенклатурная группа — «Общепит» / «Производство» (если существует)
3. Проверить подобранные значения. Особенно — Номенклатурная группа: запрос ищет элементы с такими наименованиями. Если ни один не подходит — выбрать вручную или создать новый элемент в справочнике.
4. Заполнить **«Каталог OwnCloud»** (общий с Сопуткой).
5. Установить флаг **«Проводить автоматически»** — да.
6. Нажать **«Сохранить настройки»**.

## Особенности счетов учёта

- **41.02** — счёт «Товары в розничной торговле (в НТТ по продажной стоимости)». На него приходуется как сырьё (мука, мясо), так и готовая продукция (выпечка, блюда).
- **44.01** — счёт «Издержки обращения в организациях, осуществляющих торговую деятельность». Через него проходят затраты по выпуску блюд.

См. [проводки_общепита](проводки_общепита.md) для понимания движения.

## Контроль настройки

Все параметры хранятся в регистре сведений **TL_Настройки** под ключами с префиксом **«Общепит_»**.

Для повторного открытия формы — нажать **«Загрузить настройки»**.

## Когда повторно настраивать

- При смене каталога обмена
- При смене основной организации
- При замене подразделения или счетов учёта (например при изменении учётной политики)
